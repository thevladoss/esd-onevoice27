# Редизайн лендинга «Единый голос 27» для Евро-Азиатского дивизиона

Дата: 2026-09-05. Статус: утверждён к реализации (автономный режим, допущения зафиксированы ниже).

## 1. Задача

Сделать рабочий прототип лендинга для ЕАД, который структурно и визуально повторяет
оригинал https://onevoice27.org/, но наполнен контентом Евро-Азиатского дивизиона
(https://esd.onevoice27.org/). Прототип опубликовать на бесплатном хостинге.
Данные замокать. Цель: прототип редизайна, не пиксель-перфект.

## 2. Что показало исследование

### Оригинал onevoice27.org

- Стек: Hope Software CMS на Next.js (pages router), Tailwind, Radix UI, react-map-gl + mapbox-gl.
- Анимации без библиотек: CSS `@keyframes` для фоновых петель (луч по границе кнопки через
  вращение угла conic-gradient, дрейф волн в футере, частицы в блоке ресурсов, зум атмосферы
  карточек), IntersectionObserver и CSS-переменные (`--ov-involve-item-opacity`, `-x`, `-y`),
  которые JS меняет при скролле. Hero: webm-видео глобуса + canvas с частицами (mix-blend screen).
- Шрифты: Figtree 900 для заголовков, Noto Sans для текста. Figtree без кириллицы.
- Палитра (из инлайн CSS): midnight `#070210 / #120c34 / #211a3e`, unity (индиго) `#303f83 / #3b4da1`,
  signal (маджента) `#9e439a / #bb6cae / #d28ebe`, horizon (бирюза) `#54a4ac / #7bc2c7 / #aad9dc`,
  текст `#f8f7fb`. Карточки: border `rgba(184,192,230,.22)`, radius 16px, градиентные стеклянные
  поверхности, тени `0 30px 72px rgba(18,12,52,.62)`.
- Секции: header-пилюля со скосом, hero, карта со скошенными краями и счётчиками, форма
  «Add your light», «What is OneVoice 27?» (видео + 3 карточки 1/2/3), «Turn conviction into action»
  (триптих с фото), новости с пагинацией, ресурсы (3 карточки Music/Materials/Video с панелями),
  футер с волнами.

### Версия ЕАД esd.onevoice27.org

- Тот же CMS, но шаблон по умолчанию: чёрный фон, заголовок поверх стоковой картинки, пустые
  экраны с декоративной сферой, заблокированные YouTube-вставки, одна цитата.
- Контент, который переносим: слоган «Единый голос 27 / Миссия для всех», текст
  «Единое глобальное движение. Единая весть. Евро-Азиатский дивизион присоединяется к этому
  движению», кнопки «Я участвую» и «Посмотреть карту», видео (16 роликов, YouTube ID известны),
  материалы (описание проекта, баннеры к 5 сентября 2026, вопросы по книге «Желание веков»,
  заставка для телефона, материалы на английском), цитата из «Евангелизма», стр. 122.
- Отдельное приложение карты esd-map.vercel.app: счётчики 694 человека / 248 групп, 12 стран
  дивизиона, форма регистрации (индивидуально / группа, имя, фамилия, email, телефон, страна, город).

Скриншоты и снапшоты лежат в `docs/research/`.

## 3. Допущения (принял сам, пользователь недоступен)

1. Хостинг: GitHub Pages, репозиторий `thevladoss/esd-onevoice27` (публичный), деплой через
   GitHub Actions. Адрес: `https://thevladoss.github.io/esd-onevoice27/`.
2. Язык интерфейса: русский. Английский только в идентификаторах.
3. Карта: собственный SVG на d3-geo + world-atlas без Mapbox и токенов. Огоньки замоканы
   детерминированным генератором внутри границ стран ЕАД.
4. Видео: YouTube-обложки через `img.youtube.com`, воспроизведение через lite-embed по клику.
   Фото для карточек: локальная SVG/CSS-графика, без хотлинка на CDN ЕАД.
5. Форма ничего не отправляет: успешная отправка добавляет огонёк на карту и увеличивает счётчик
   в памяти страницы.
6. Одна страница, якорная навигация. Панели ресурсов открываются на месте.

## 4. Стек

| Слой | Выбор | Почему |
|---|---|---|
| Сборка | Vite 8 + React 19 + TypeScript | быстрый статический билд под Pages |
| Стили | Tailwind CSS v4 (`@tailwindcss/vite`) + CSS-переменные токенов | как в оригинале, токены переносим 1:1 |
| Анимации появления | `motion` (framer-motion v13, `whileInView`, stagger) | декларативно, дёшево, заменяет ручной IntersectionObserver |
| Фоновые анимации | CSS `@keyframes` + `@property` для угла conic-gradient | так сделан оригинал; луч по кнопке, дрейф волн, частицы |
| Hero-глобус | собственный canvas (точки на сфере, вращение, glow, mix-blend screen) | заменяет webm-видео, весит 0 байт |
| Карта | d3-geo, d3-zoom, topojson-client, world-atlas (110m) | бесплатно, полный контроль над стилем |
| Шрифты | Onest 800/900 (заголовки, кириллица) + Noto Sans 400/700 (текст), Google Fonts | Figtree без кириллицы, Onest ближайший геометрический аналог |
| Тесты | Vitest + Testing Library + jsdom; Playwright (MCP) для визуального smoke | test-as-you-go |
| Деплой | GitHub Actions `actions/deploy-pages` | бесплатно, без внешних CLI |

## 5. Структура страницы и контент

Порядок и якоря повторяют оригинал.

1. **Header** `#top`. Плавающая стеклянная пилюля со скосом 20°, логотип «Единый голос 27 /
   Миссия для всех», меню: Что это? (`#about`), Участвовать (`#involve`), Новости (`#news`),
   Материалы (`#resources`). На мобильном бургер и оверлей.
2. **Hero** `#hero`. Canvas-глобус справа, звёздное поле, надзаголовок «Единое глобальное движение»,
   H1 с градиентом «Вместе, единым голосом», подзаголовок про ЕАД, кнопка «Зажечь свой свет»
   (`#light-form`) с вращающимся лучом по границе.
3. **Карта** `#map`. Скошенные верх и низ (clip-path polygon). Надзаголовок «Все вместе», H2
   «Зажигаем свет по всему дивизиону». Счётчики «Человек 694» (маджента) и «Групп 248» (бирюза)
   с анимацией счёта при появлении. Чипы 12 стран плюс «Весь дивизион»: клик центрирует карту.
   Огоньки двух цветов (люди / группы) с пульсацией. Зум и панорамирование.
4. **Форма** `#light-form`. «Участвуйте с нами» / «Зажгите свой свет». Тип: «Индивидуальный свет»
   или «Групповой маяк». Поля: имя, фамилия, страна (select из 12), город, email, согласие.
   Кнопка градиентная. После отправки: тост, новый огонёк, счётчик +1.
5. **О проекте** `#about`. «Глобальное влияние» / «Что такое Единый голос 27?». Абзац про сентябрь
   2027 и 2000-летие крещения Иисуса. Видео-блок (YouTube `YpLD6p-z00g`, обложка + кнопка play).
   Три карточки: 1 Проект, 2 Подготовка, 3 Цель, с маркерами и итоговой фразой (перевод оригинала).
6. **Участие** `#involve`. «Как включиться» / «От убеждения к действию». Триптих: «Личное
   преображение» (молитва, «Желание веков», Даниил и Откровение), «Материалы для церкви»
   (брендбук, баннеры, заставки), «Делиться» (видео, соцсети). Иллюстрации: SVG-графика.
7. **Новости** `#news`. «На каждом канале» / «Каждая платформа становится голосом». 9 мок-новостей
   ЕАД по 6 на страницу с пагинацией. Обложки: YouTube-превью роликов ЕАД.
8. **Ресурсы** `#resources`. «Ресурсы» / «Всё, что нужно для старта». Асимметричная сетка карточек
   Музыка / Материалы / Видео с дрейфующими частицами. Клик раскрывает панель под сеткой:
   Материалы (5 позиций со ссылками на реальные страницы ЕАД), Видео (16 роликов), Музыка
   (заглушка «официальная песня скоро»).
9. **Цитата** `#quote`. Текст из «Евангелизма», стр. 122, на градиентном фоне с картой-силуэтом.
10. **Footer**. Дрейфующие волны, логотип, «Официальный сайт Церкви христиан адвентистов седьмого
    дня», © 2026 Евро-Азиатский дивизион, ссылки на esd.adventist.org и onevoice27.org.

## 6. Архитектура кода

```
src/
  main.tsx, App.tsx
  styles/tokens.css        # --ov-* палитра, шрифты, тени
  styles/global.css        # Tailwind + keyframes + утилиты (glass, skew, beam)
  data/                    # моки: countries.ts, lights.ts, news.ts, videos.ts, materials.ts, copy.ts
  lib/                     # geo.ts (проекция, генератор огоньков), format.ts, useCountUp.ts
  components/
    layout/Header.tsx, Footer.tsx, Section.tsx, Eyebrow.tsx, GradientTitle.tsx, Button.tsx
    hero/Hero.tsx, GlobeCanvas.tsx, Starfield.tsx
    map/MapSection.tsx, EsdMap.tsx, Counters.tsx, CountryChips.tsx
    form/LightForm.tsx
    about/About.tsx, StepCard.tsx, VideoEmbed.tsx
    involve/Involve.tsx
    news/News.tsx
    resources/Resources.tsx, ResourcePanel.tsx
    quote/Quote.tsx
  state/lights.tsx         # контекст: список огоньков + счётчики, addLight()
```

Каждый компонент: один файл, один экспорт, данные через props или контекст огоньков.
Моки в `data/` типизированы, генератор огоньков детерминирован (seed), чтобы тесты были стабильны.

## 7. Тестирование

- Unit (Vitest): генератор огоньков даёт точки внутри bbox стран; форматирование чисел
  (`694` → `694`, `4268` → `4 268`); валидация формы; пагинация новостей; редьюсер огоньков.
- Component (Testing Library): форма добавляет огонёк и увеличивает счётчик; чипы стран меняют
  активную страну; панели ресурсов переключаются; навигация содержит четыре якоря.
- Smoke (Playwright MCP после `vite build` + `vite preview`): все секции в DOM, нет ошибок консоли,
  скриншоты десктоп 1440 и мобильный 390.
- CI: `npm test` и `npm run build` перед деплоем в том же workflow.
