# Requirements: Единый голос 27 — лендинг ЕАД (редизайн)

**Defined:** 2026-09-05
**Core Value:** Посетитель видит живой лендинг уровня оригинала onevoice27.org про ЕАД, понимает суть «Единого голоса 27», видит карту движения по дивизиону и может «зажечь свой свет».

## v1 Requirements

Требования первого релиза (прототип). Каждое привязано к фазе roadmap.

### Каркас и оболочка (SHELL)

- [x] **SHELL-01**: Посетитель видит плавающий header-пилюлю со стеклянным фоном и скосом, логотипом «Единый голос 27 / Миссия для всех» и меню из четырёх якорей: Что это? (`#about`), Участвовать (`#involve`), Новости (`#news`), Материалы (`#resources`)
- [x] **SHELL-02**: На экране до 768px меню сворачивается в бургер; оверлей открывается и закрывается кнопкой и клавишей Esc, блокирует скролл и возвращает фокус
- [x] **SHELL-03**: Клик по пункту меню плавно прокручивает к секции с учётом высоты header
- [x] **SHELL-04**: Посетитель видит footer с дрейфующими волнами, логотипом, подписью «Официальный сайт Церкви христиан адвентистов седьмого дня», строкой «© 2026 Евро-Азиатский дивизион» и ссылками на esd.adventist.org и onevoice27.org
- [x] **SHELL-05**: Страница использует токены палитры оригинала (midnight, unity, signal, horizon, paper), шрифты Onest для заголовков и Noto Sans для текста, стеклянные карточки с border `rgba(184,192,230,.22)`, radius 16px и тенью оригинала
- [x] **SHELL-06**: `index.html` содержит `lang="ru"`, title «Единый голос 27 — Евро-Азиатский дивизион», описание и базовые Open Graph теги

### Hero (HERO)

- [x] **HERO-01**: Посетитель видит надзаголовок «Единое глобальное движение», H1 с маджента-бирюзовым градиентом «Вместе, единым голосом» и подзаголовок «Единая весть. Евро-Азиатский дивизион присоединяется к этому движению»
- [x] **HERO-02**: Справа в hero вращается canvas-глобус из частиц с фиолетово-бирюзовым свечением поверх звёздного поля; анимация останавливается при `prefers-reduced-motion`, скрытой вкладке и когда hero вне вьюпорта
- [x] **HERO-03**: Кнопка «Зажечь свой свет» ведёт на `#light-form`, имеет градиентную заливку и вращающийся луч по границе (conic-gradient через `@property`), с fallback без анимации

### Карта дивизиона (MAP)

- [x] **MAP-01**: Посетитель видит секцию со скошенными верхним и нижним краями, надзаголовком «Все вместе» и H2 «Зажигаем свет по всему дивизиону»
- [x] **MAP-02**: SVG-карта на d3-geo показывает 12 стран ЕАД (Россия, Беларусь, Молдова, Грузия, Армения, Азербайджан, Казахстан, Кыргызстан, Таджикистан, Туркменистан, Узбекистан, Афганистан) подсвеченными на фоне соседних стран, без разрыва России на антимеридиане
- [x] **MAP-03**: На карте отображаются замоканные огоньки: 694 человека (маджента) и 248 групп (бирюза), детерминированно сгенерированные внутри границ стран; не более 40 огоньков пульсируют одновременно
- [x] **MAP-04**: Счётчики «Человек» и «Групп» показывают значения из состояния огоньков с форматированием пробелом (`4 268`) и анимацией счёта при первом появлении; при reduced motion сразу конечное значение
- [x] **MAP-05**: Посетитель может зумить и панорамировать карту (колесо с Ctrl/⌘, перетаскивание, два пальца на touch), обычный скролл страницы над картой не перехватывается
- [x] **MAP-06**: Чипы «Весь дивизион» и 12 стран центрируют карту на выбранной стране с плавным переходом; активный чип выделен; управление доступно с клавиатуры

### Форма «Зажгите свой свет» (FORM)

- [x] **FORM-01**: Посетитель видит секцию с надзаголовком «Участвуйте с нами», H2 «Зажгите свой свет» и выбором типа: «Индивидуальный свет» или «Групповой маяк» с описаниями как в оригинале
- [x] **FORM-02**: Форма содержит поля имя, фамилия, страна (select из 12 стран ЕАД), город, email и чекбокс согласия; обязательные поля валидируются на клиенте с понятными сообщениями на русском
- [x] **FORM-03**: После успешной отправки появляется тост `role="status"` «Ваш свет зажжён», на карту добавляется новый огонёк в выбранной стране, соответствующий счётчик увеличивается на 1, форма сбрасывается; ничего не отправляется на сервер

### О проекте (ABOUT)

- [x] **ABOUT-01**: Посетитель видит надзаголовок «Глобальное влияние», H2 «Что такое Единый голос 27?» с градиентом и абзац о сентябре 2027 и 2000-летии крещения Иисуса
- [x] **ABOUT-02**: Видео-блок показывает обложку YouTube-ролика `YpLD6p-z00g` с кнопкой play; по клику загружается iframe `youtube-nocookie.com`
- [x] **ABOUT-03**: Три стеклянные карточки «1 Проект», «2 Подготовка», «3 Цель» с градиентными номерами, маркированными списками и итоговой фразой (русский перевод содержания оригинала)

### Участие (INVOLVE)

- [x] **INVOLVE-01**: Посетитель видит надзаголовок «Как включиться», H2 «От убеждения к действию» и триптих карточек «Личное преображение», «Материалы для церкви», «Делиться» с SVG-иллюстрациями, заголовками и ссылками-действиями на соответствующие секции

### Новости (NEWS)

- [x] **NEWS-01**: Посетитель видит надзаголовок «На каждом канале», H2 «Каждая платформа становится голосом» и сетку из 9 мок-новостей ЕАД с обложками из YouTube-превью, датой, заголовком и ссылкой
- [x] **NEWS-02**: Новости показываются по 6 на страницу с клиентской пагинацией (1, 2, стрелка); переключение страницы не перезагружает страницу

### Ресурсы (RES)

- [x] **RES-01**: Посетитель видит надзаголовок «Ресурсы», H2 «Всё, что нужно для старта» и асимметричную сетку из трёх карточек Музыка / Материалы / Видео с цветными индикаторами и дрейфующими частицами на фоне
- [x] **RES-02**: Клик по карточке раскрывает панель под сеткой; панель «Материалы» содержит 5 позиций со ссылками на реальные страницы ЕАД (описание проекта .docx, баннеры к 5 сентября 2026, вопросы по книге «Желание веков», заставка для телефона, материалы на английском)
- [x] **RES-03**: Панель «Видео» показывает 16 роликов ЕАД (YouTube ID и названия из PROJECT.md) как фасады с обложкой и lite-embed по клику; панель «Музыка» показывает честную заглушку «Официальная песня скоро»
- [x] **RES-04**: Открытую панель можно закрыть, повторный клик по активной карточке сворачивает её; состояние доступно с клавиатуры (`aria-expanded`, `aria-controls`)

### Цитата (QUOTE)

- [x] **QUOTE-01**: Посетитель видит цитату из «Евангелизма», стр. 122 (два абзаца из esd.onevoice27.org) на градиентном фоне с силуэтом карты и подписью источника

### Анимации и доступность (MOTION)

- [x] **MOTION-01**: Секции и карточки появляются при скролле через `motion` (`whileInView`, stagger) один раз; при `prefers-reduced-motion: reduce` контент виден сразу без анимаций
- [x] **MOTION-02**: Фоновые CSS-анимации (луч кнопки, частицы ресурсов, волны и гало футера, пульсация огоньков) отключаются при reduced motion
- [x] **MOTION-03**: Страница корректно выглядит и работает на ширинах 390, 768, 1024 и 1440px без горизонтального скролла; все интерактивные элементы имеют видимый фокус и aria-атрибуты
- [x] **MOTION-04**: В консоли браузера нет ошибок и 404 на собранном билде

### Качество и деплой (QA)

- [x] **QA-01**: Vitest-тесты покрывают генератор огоньков (точки внутри bbox стран, детерминизм), форматирование чисел, валидацию формы, редьюсер огоньков и пагинацию новостей
- [x] **QA-02**: Component-тесты покрывают форму (добавление огонька и счётчик), чипы стран, панели ресурсов и навигацию header
- [x] **QA-03**: GitHub Actions workflow запускает `npm ci`, `npm test`, `npm run build` и деплоит `dist` на GitHub Pages при пуше в `main`
- [x] **QA-04**: Сайт доступен по адресу `https://thevladoss.github.io/esd-onevoice27/` и совпадает с локальным `vite preview`; Playwright smoke подтверждает наличие всех секций и чистую консоль на 1440 и 390px

## Out of Scope

| Feature | Reason |
|---------|--------|
| Бэкенд и реальная отправка формы | Прототип на статике; персональные данные требуют отдельного решения |
| CMS и админка | Цель — показать редизайн, не заменить Hope Software CMS |
| Тайловая карта (Mapbox/MapLibre) | Нужны токены и внешние тайлы; SVG на d3-geo даёт контроль над стилем |
| Пиксель-перфект копия | Figtree без кириллицы, исходного webm нет; цель «похоже и качественно» |
| Хотлинк фото с CDN ЕАД | Чужой трафик и права; SVG-графика и YouTube-превью |
| Cookie-баннер и consent-гейт | Нечего трекать; гейт ломает демо видео |
| Автоплей видео, three.js-глобус, роутинг `?page=`, бесконечный скролл, светлая тема, аналитика, SSR | Анти-фичи из FEATURES.md: вес, сложность или ломают демо |

### Точность оригинала (FID)

- [ ] **FID-01**: Шапка и главное меню повторяют оригинал onevoice27.org вплоть до цветов и анимаций: пилюля-параллелограмм со скосом 20°, градиентная рамка и стекло, белый логотип, пункты меню с градиентной заливкой текста на ховере, скрытие шапки при прокрутке вниз, бургер-крест и полноэкранный оверлей мобильного меню
- [ ] **FID-02**: Фоны всех секций растянуты на всю ширину окна и повторяют градиенты, скосы и подложки оригинала; карта заливает всю ширину
- [ ] **FID-03**: Кнопка hero (и submit формы) повторяет оригинал: конический луч по рамке и сетка точек, проявляющаяся вслед за лучом через mask-image на той же переменной угла
