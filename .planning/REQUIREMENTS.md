# Requirements: Единый голос 27 — лендинг ЕАД, milestone v1.1

**Defined:** 2026-09-06
**Core Value:** Посетитель открывает страницу и видит красивый, живой лендинг уровня оригинала onevoice27.org, но про ЕАД: узнаёт, что такое «Единый голос 27», видит карту движения по дивизиону и может «зажечь свой свет».

Источник: шесть правок пользователя после приёмки v1.0 и спецификация
`docs/superpowers/specs/2026-09-06-design-fixes-v1.1-design.md` (точные значения CSS оригинала, дампы в
`docs/research/v1.1/`). Номера пунктов спецификации совпадают с REQ-ID ниже.

## v1 Requirements

### Стекло (GLASS)

- [x] **GLASS-01**: Посетитель видит стеклянные карточки с полупрозрачной поверхностью оригинала: утилита `glass` и токены `--glass-surface`, `--glass-border`, `--shadow-card` дают `linear-gradient(145deg, rgb(255 255 255 / .045), transparent 30%), linear-gradient(180deg, rgb(49 41 77 / .44), rgb(18 12 52 / .62))`, рамку `1px solid rgb(239 237 245 / .18)`, тень `inset 0 1px 0 rgb(255 255 255 / .035), 0 20px 46px rgb(3 2 18 / .24)`, `backdrop-filter: blur(14px) saturate(112%)`, ховер с рамкой `rgb(143 157 214 / .34)`
- [x] **GLASS-02**: Карточки шагов About используют поверхность GLASS-01 без переопределения фона, сохраняя акцентную линию и разделитель
- [x] **GLASS-03**: Карточки ресурсов используют поверхность оригинала `linear-gradient(180deg, rgb(255 255 255 / .075), transparent 34%), linear-gradient(145deg, rgb(49 41 77 / .44), rgb(18 12 52 / .62))` и `blur(14px) saturate(125%)`
- [x] **GLASS-04**: Триптих Involve: рамка без размытия, карточки с поверхностью `rgb(33 26 62 / .48)`, швом `1px solid rgb(239 237 245 / .15)`, тенью рамки оригинала и ховером `rgb(49 41 77 / .54)`
- [x] **GLASS-05**: Счётчики карты не меняются (уже совпадают с оригиналом)
- [x] **GLASS-06**: Заголовки секций плоские `rgb(239 237 245)`, градиентный только About (`linear-gradient(104deg, rgb(227 175 210) 2%, rgb(143 157 214) 52%, rgb(123 194 199))`); hero h1 остаётся градиентным

### Карта (MAP)

- [ ] **MAP-01**: Карта и форма живут в одной ленте `.map-band` с единой скошенной подложкой `rgb(18 12 52)` (`clip-path: polygon(0 var(--map-wedge), 100% 0, 100% 100%, 0 100%)`), секции карты и формы прозрачные, без своих подложек и `margin-top`
- [ ] **MAP-02**: Нижний орб центрирован на нижнем крае карты справа и светит в область формы без обрезки; на <768px орб — полоса во всю ширину
- [ ] **MAP-03**: Между низом карты и формой нет второй линии: единственная граница — скос карты (`clip-path: polygon(0 var(--map-wedge), 100% 0, 100% calc(100% - var(--map-wedge)), 0 100%)`); вертикальная выборка пикселей по x = 200 и x = 1240 на отрезке «низ карты + 120px» не содержит перепада яркости > 6, кроме линии скоса
- [ ] **MAP-04**: Карта видна сразу при прокрутке: reveal-обёртка вокруг `.map-container` убрана, огоньки не затухают
- [ ] **MAP-05**: Огоньки как в слоях Mapbox оригинала: ядро 2.2px с обводкой `#fff` 0.9px opacity .5, свечение радиальным градиентом с «дыханием» радиуса 6→12px и opacity .30→.60, период ~2.6s, пять фазовых корзин (`index % 5`), цвета `rgb(158 67 154)` / `rgb(84 164 172)`; анимация `light-pulse` удалена, кольцо нового огонька сохранено
- [ ] **MAP-06**: Дыхание реализовано через `@property --halo-k` на пяти группах с fallback на opacity; ≥ 50 fps на карте с 942 огоньками в Chrome 1440×900, иначе остаётся только дыхание opacity
- [ ] **MAP-07**: Карта и огоньки рисуются в первом кадре после монтирования; `prefers-reduced-motion: reduce` выключает дыхание

### Форма (FORM)

- [x] **FORM-01**: Форма без стеклянной карточки-обёртки; состояние без выбранного типа при старте; при «Групповой маяк» появляется обязательное поле «Название организации»; валидация и тесты покрывают оба состояния и ошибки «Выберите тип света» / «Укажите название организации»
- [x] **FORM-02**: Подписи на русском по спецификации (тип света, две карточки с описаниями, Название организации, Имя, Фамилия, Страна, Город, Электронная почта, согласие, кнопка «Зажечь свой свет →»), обязательные поля помечены звёздочкой `rgb(252 165 165)` с `title="Обязательно"`
- [x] **FORM-03**: Карточки типа света со стилями оригинала: поверхность `rgb(33 26 62 / .42)`, маячок `::before` 40×40, точка-радио 16px, выбранное состояние с рамкой `rgb(123 194 199 / .72)` и свечением `0 0 24px var(--halo)`, ховер `translateY(-2px)`
- [x] **FORM-04**: Поля 54px с radius 16px, фоном `rgb(33 26 62 / .58)`, рамкой `rgb(239 237 245 / .18)`, фокусом `rgb(170 217 220)` + `0 0 0 3px rgb(123 194 199 / .12)`; чекбокс 18px с `accent-color`; кнопка `size="form"` во всю ширину с `margin-top: 8px`
- [x] **FORM-05**: Шапка секции: eyebrow `rgb(170 217 220)`, плоский белый заголовок, лид 18px/1.65 `rgb(219 215 232)`, колонка 42rem, отступы 64px, форма через 48px после лида; id `light-form` и тост успеха сохранены

### Превью (MEDIA)

- [x] **MEDIA-01**: Карточки новостей 16:9 с `object-fit: cover`: чёрных полос YouTube-превью нет (средняя яркость 6px-полос у верхнего и нижнего края обложки > 12)
- [x] **MEDIA-02**: Панель заголовка как у оригинала (inset 4px, padding `clamp(18px, 2.4vw, 28px)`, radius 12px, заголовок 800 с `line-clamp: 3`, дата `rgb(170 217 220)`), оверлей обложки оригинала; ховер: картинка `scale(1.035)` 760ms, панель `rgb(247 239 232 / .96)` с текстом `rgb(18 12 52)`, рамка карточки `rgb(143 157 214 / .38)`; reduced motion без масштабирования
- [x] **MEDIA-03**: Превью роликов (`VideoEmbed` в About и в панели «Видео») — контейнер 16:9 с `object-fit: cover`, без полос и лишней обрезки

### Ресурсы (RES)

- [x] **RES-01**: Раскладка ≥1024px по сетке оригинала `minmax(0, 320fr) minmax(0, 528fr) minmax(0, 272fr)` с gap 16px: текст `1 / 2` (528/523, пунктирная рамка), музыка `1 / 1` (320/296), материалы `1 / 3` (272/336, `align-self: end`), видео `2 / 2` (`min(69.697%, 368px)`, 368/256); <1024px — колонка, карточки `min(100%, 328px)` × 248px
- [x] **RES-02**: Карточка ресурса: индикатор (подпись + точка 16px акцента), контент внизу (заголовок 800, описание .875rem, действие с подчёркиванием `scaleX(.34→1)`), ховер `translateY(-4px)` с рамкой акцента за 420ms; акценты `rgb(143 157 214)` / `rgb(123 194 199)` / `rgb(210 142 190)`
- [x] **RES-03**: Панели полноэкранные: fixed-контейнер z 10000, слои `rgb(132 53 127)` и `rgb(59 77 161)` въезжают справа за 620ms со сдвигом 90ms, панель проявляется с задержкой 180ms; закрытие обратное; scroll lock, фокус на «Назад», `Escape`, возврат фокуса на карточку, deep link `#resources-materials`, reduced motion без переходов
- [x] **RES-04**: Внутренности панели по оригиналу: кнопка «Назад», заголовок, описание, сетка файлов `repeat(auto-fill, minmax(min(100%, 17.5rem), 1fr))`, карточки файлов с бейджем типа и кнопкой «Скачать»/«Открыть», языковые группы `<details>`
- [x] **RES-05**: Наполнение: «Музыка» — три файла оригинала (Sheet Music PDF, Theme Song no vocals ZIP, Music Lyrics MOV) с пояснением на русском; «Материалы» — группа ЕАД на русском (4 позиции) и группы English/Spanish/Portuguese/French из оригинала (данные в `src/data/resourceFiles.ts`); «Видео» — 16 роликов ЕАД и карточка «Video backgrounds» ZIP; заглушка `MusicPlaceholder` удалена
- [x] **RES-06**: Фон секции при открытой панели красится в цвет карточки (`rgb(22 29 61)` / `rgb(25 47 54)` / `rgb(50 16 47)`), атмосфера и частицы сохранены

### Футер (FOOT)

- [x] **FOOT-01**: Футер в одну колонку по центру: `width: min(100% - 32px, 1152px)`, gap `clamp(20px, 3vw, 34px)`, padding-block `clamp(72px, 10vw, 124px)`; порядок: логотип `clamp(190px, 26vw, 300px)` с `drop-shadow(0 0 22px rgb(91 90 214 / .13))`, подпись `min(100%, 680px)`, ссылки, юридический текст `.75rem` `rgb(239 237 245 / .66)`; скос, волны и гало сохранены

## Out of Scope

| Feature | Reason |
|---------|--------|
| Изменение текстов секций, кроме подписей формы и описаний панелей | Пользователь: «по содержанию вроде даже всё ок» |
| Геокодер адреса как в оригинале (Mapbox) | Нужен токен; страна + город покрывают сценарий прототипа |
| Скачивание файлов через свой прокси | Ссылки ведут напрямую на hope-documents и SharePoint оригинала |
| Копирование reveal-поведения оригинала (у него его нет) | Наши reveal-каскады остаются: пользователь их не оспаривал |
| Пиксель-перфект по всем секциям | Объём — рабочий прототип; точность требуется по шести названным пунктам |
