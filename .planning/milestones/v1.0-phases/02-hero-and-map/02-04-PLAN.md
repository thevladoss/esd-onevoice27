## Phase Goal

**As a** посетитель лендинга, **I want to** увидеть эффектный hero с вращающимся глобусом и кнопкой «Зажечь свой свет», а ниже живую карту ЕАД с огоньками, счётчиками и переключением стран, **so that** почувствовать масштаб движения по дивизиону и перейти к форме, чтобы зажечь свой свет.

Этот план делает карту интерактивной: зум и панорамирование без перехвата скролла, чипы стран с плавным полётом камеры, подсказка о жестах.

<objective>

Purpose: без зума и чипов карта остаётся картинкой; оригинал и esd-map.vercel.app дают исследовать карту, чипы дублируют это для клавиатуры.

import type { RefObject } from "react";
import type { ZoomTransform } from "d3-zoom";
export interface UseMapZoomOptions {
  width: number;
  height: number;
  enabled: boolean;                    // false при ошибке карты или до измерения
  onUserZoom?: (k: number) => void;    // только для событий с sourceEvent (жест пользователя)
}
export interface MapZoomApi {
  transform: ZoomTransform;            // zoomIdentity до первого события
  dragging: boolean;
  zoomTo: (target: ZoomTransform, animate: boolean) => void; // animate=false применяет мгновенно
}
export const ZOOM_MIN = 1; export const ZOOM_MAX = 8; export const ZOOM_PAD = 200; export const FLIGHT_MS = 600;
export function useMapZoom(svgRef: RefObject<SVGSVGElement | null>, opts: UseMapZoomOptions): MapZoomApi;
