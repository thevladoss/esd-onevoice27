1. `src/lib/scrollToSection.ts`: `export function scrollToSection(hash: string, headerHeight: number): boolean`. Если `hash === "#top"` → `window.scrollTo({ top: 0, behavior })`, вернуть `true`. Иначе `document.getElementById(hash.replace(/^#/, ""))`; нет элемента → вернуть `false` без побочных эффектов. `behavior` = `"auto"`, когда `window.matchMedia?.("(prefers-reduced-motion: reduce)").matches` истинно, иначе `"smooth"`. `top = Math.max(0, el.offsetTop - headerHeight - 16)` (по решению CONTEXT: `offsetTop`, поправка 16px, `scrollIntoView` не использовать). 2. `src/lib/useActiveSection.ts`: `export function useActiveSection(ids: readonly string[], enabled: boolean): string | null`. При `enabled === false` возвращает `null` и наблюдателей не создаёт. Иначе в `useEffect` создаёт один `IntersectionObserver` с `rootMargin: "-40% 0px -55% 0px"` и `threshold: 0`, наблюдает элементы по `ids`, при callback берёт среди `isIntersecting` запись с наибольшим `intersectionRatio` (при равенстве первую по порядку в `ids`) и сохраняет её `target.id` в state; `disconnect` в cleanup. Без `IntersectionObserver` в `window` (старый браузер) хук возвращает `null`. В jsdom мок-наблюдатель никогда не вызывает callback, поэтому в тестах хук стабильно даёт `null`.
