# Phase 5 — UI Design Contract

> Визуальный и интеракционный контракт фазы полировки. Фаза не добавляет секций и не вводит новых токенов: она фиксирует контракт движения (reveal при скролле), единую политику `prefers-reduced-motion` для всех анимаций проекта, чеклист адаптива на 390/768/1024/1440, контракт доступности и приёмочный smoke. Дизайн-система целиком наследуется из `01-UI-SPEC.md`.

### Умолчания, принятые в этом документе

| Значение | Почему |
|----------|--------|
| `y: 16px` и `amount: 0.15` для reveal ниже 768px | `05-CONTEXT.md` отдал мобильные пороги на усмотрение. На 390×844 сдвиг 24px съедает заметную долю экрана, а `amount: 0.2` для высоких блоков срабатывает поздно |
| `margin: "0px 0px -6% 0px"` ниже 768px | 10% от 844px даёт 84px мёртвой зоны внизу, блок появляется рывком уже после того, как пользователь его прочитал |
| Токены `--dur-reveal: 700ms`, `--ease-reveal`, `--stagger-reveal: 80ms` | Фаза 1 держит длительности в `:root`. Reveal встаёт в тот же реестр, чтобы значение не дублировалось в JSX |
| Контракт `data-anim` на декоративных петлях | Фазы 1–4 верстают утилитами Tailwind, устойчивых классов у анимированных слоёв нет. Атрибут даёт один селектор для блока reduced motion и один список для аудита |
| Blanket-сброс `*, *::before, *::after` внутри reduce | Страховка от анимации, которую фаза 5 не нашла глазами. Именованные петли гасятся отдельно и явно |
| Chunk `vendor-map` для `d3-*`, `topojson-client`, `world-atlas` | `05-CONTEXT.md` оставил способ разбиения на усмотрение. Отдельный чанк снимает предупреждение 700 КБ и не требует ленивой загрузки секции |
| Скриншот `docs/qa/final-reduced-motion.jpeg` сверх трёх обязательных | Единственное доказательство, что при reduce страница не осыпалась в пустые блоки |
| Проверка reflow на 320px | WCAG 1.4.10. Стоит две минуты, ловит скосы и абсолютные слои, которые на 390 ещё помещаются |

### Разрешение конфликтов с `05-CONTEXT.md`

`05-CONTEXT.md` написан до `01-UI-SPEC.md` и в четырёх местах называет значения, которых фаза 1 уже зафиксировала иначе. Дизайн-систему задаёт фаза 1, побеждают её значения. Исполнитель берёт правый столбец.

| Пункт | `05-CONTEXT.md` | Действующее значение (`01-UI-SPEC.md`) |
|-------|-----------------|----------------------------------------|
| Кольцо фокуса | `outline: 2px solid #7bc2c7; outline-offset: 3px` | `outline: 2px solid var(--color-horizon-200)` (`#aad9dc`), `outline-offset: 4px`, утилита `focus-ring` уже в `global.css`. Контраст `#aad9dc` на midnight-950 равен 11.4:1 против 10.4:1 у `#7bc2c7` |
| Текст skip-link | `К содержанию` | `Перейти к содержимому` |
| Цель skip-link и id главного ландмарка | `main id="content"` | `<main id="main">`, ссылка ведёт на `#main` |
| Непрозрачность текста на стекле | «поднять `paper/.8` до `.86`» | Остаётся `.8`. Порог фазы 1 равен 0.72 при измеренных 8.9:1, поднимать нечего |

Фаза 5 не меняет ни одного токена, ни одного размера шрифта и ни одного цвета. Всё, что она правит в существующих компонентах: обёртки `Reveal`, атрибуты `data-anim`, недостающие `aria-*`, блок reduced motion и `manualChunks`.

## Spacing Scale

Шкала фазы 1 действует без изменений: 4 / 8 / 16 / 24 / 32 / 48 / 64 / 96px, все кратны 4. Фаза 5 новых отступов не вводит.

Значения, которыми фаза 5 пользуется:

| Токен | Значение | Где в фазе 5 |
|-------|----------|--------------|
| xs | 4px | `outline-offset` внутри обрезанных контейнеров считается от 4px в минус |
| sm | 8px | Вертикальный зазор рядов чипов, `padding-block` ссылок footer, дистанция stagger не измеряется в пикселях |
| md | 16px | Сдвиг reveal ниже 768px (`y: 16`) |
| lg | 24px | Сдвиг reveal от 768px (`y: 24`) |
| 2xl | 48px | Тач-цели: бургер 48×48, пункты оверлея 48px |
| 4xl | 96px | `scroll-padding-top: 96px`, от него считается проверка «header не перекрывает заголовок» |

**Exceptions:** 44×44px как минимальная тач-цель (WCAG 2.5.8, не отступ), 40px высота чипа карты из фазы 2 (компенсируется зазором 8px между рядами и горизонтальным padding 16px, суммарная область нажатия 48px по вертикали).

## Typography

Фаза 5 не добавляет ни одного текстового элемента и ни одного размера. Таблица приведена как реестр, по которому идёт аудит.

| Role | Token | Size | Family | Weight | Line Height |
|------|-------|------|--------|--------|-------------|
| Body | `--text-base` | 16px | Noto Sans | 400 | 1.6 |
| Label | `--text-sm` | 14px | Noto Sans | 700 | 1.2 |
| Heading | `--text-section` | clamp 28 → 40px | Onest | 700 | 1.1 |
| Display | `--text-wordmark` | clamp 18 → 22px | Onest | 900 | 1.05 |

Рабочая пара насыщенностей: **400 / 700**. Итоговый реестр исключений, которые аудит фазы 5 принимает и за пределы которого не выпускает:

| Насыщенность | Где разрешена | Кем зафиксирована |

| Onest 900 | Вордмарк в header, вордмарк в footer, H1 hero, числа счётчиков, номера карточек 1/2/3 | Фазы 1, 2, 3 |

## Motion Contract

### Токены движения

Добавляются в `:root` внутри `global.css`, рядом с `--dur-ui`, `--dur-header`, `--dur-underline` из фазы 1.

```css
:root {
  --dur-reveal: 700ms;
  --ease-reveal: cubic-bezier(0.22, 1, 0.36, 1); /* совпадает с --ease-ui */
  --stagger-reveal: 80ms;
  --reveal-shift: 24px;
}

@media (max-width: 767px) {
  :root { --reveal-shift: 16px; }
}
```

В JSX те же значения приходят из констант `src/components/layout/reveal.constants.ts`, чтобы CSS и motion не разъезжались:

```ts
export const REVEAL_DURATION = 0.7;              // секунды, motion считает в секундах
export const REVEAL_EASE = [0.22, 1, 0.36, 1] as const;
export const REVEAL_STAGGER = 0.08;
export const REVEAL_DELAY_CHILDREN = 0.05;
```

### `Reveal` (`src/components/layout/Reveal.tsx`)

| Свойство | Значение |
|----------|----------|
| Элемент | `motion.div` по умолчанию, семантика переопределяется пропом `as` |
| `initial` | `{ opacity: 0, y: shift }`, где `shift` равен 24 от 768px и 16 ниже 768px |
| `whileInView` | `{ opacity: 1, y: 0 }` |
| `transition` | `{ duration: 0.7, ease: [0.22, 1, 0.36, 1], delay }` |
| `viewport` (≥768px) | `{ once: true, amount: 0.2, margin: "0px 0px -10% 0px" }` |
| `viewport` (<768px) | `{ once: true, amount: 0.15, margin: "0px 0px -6% 0px" }` |
| Пропы | `delay?: number` (секунды, по умолчанию 0), `as?: ElementType`, `className?: string`, `children` |
| При `useReducedMotion() === true` | Рендерит `<As className={className}>{children}</As>` без motion-обёртки, без `style`, без `initial` |

Ширина читается один раз при монтировании через `window.matchMedia("(max-width: 767px)")`, ресайз пересчёт не запускает: reveal срабатывает один раз и повторно не проигрывается.

### `RevealGroup` и `RevealItem`

Сетки карточек анимируются через `variants`, а не через `delay` на каждом элементе: так задержка считается от появления контейнера, а не от монтирования.

```tsx
const groupVariants = {
  hidden: {},
  visible: { transition: { staggerChildren: 0.08, delayChildren: 0.05 } },
};

const itemVariants = {
  hidden: { opacity: 0, y: "var(--reveal-shift)" },
  visible: { opacity: 1, y: 0, transition: { duration: 0.7, ease: [0.22, 1, 0.36, 1] } },
};
```

| Правило | Значение |
|---------|----------|
| Максимум элементов в одной группе | 6. Последний стартует на 0.4s, вся волна укладывается в 1.1s |
| Сетка новостей (6 карточек на страницу) | Одна группа, stagger 0.08 |
| Смена страницы пагинации | Reveal не перезапускается: `once: true` уже отработал, новые карточки появляются мгновенно |
| При `useReducedMotion() === true` | `RevealGroup` и `RevealItem` рендерят обычные элементы, stagger не создаётся |

### Взаимодействие reveal со стеклом

`transform` на предке ломает выборку фона у `backdrop-filter`: пока обёртка сдвинута, блюр берёт неверную подложку. Правила:

1. `Reveal` анимирует только `opacity` и `y`. Никаких `scale`, `filter`, `box-shadow`.
2. Конечное состояние `y: 0` обязано оставлять `transform: none` на узле, иначе стекло остаётся в неправильном контексте. Проверка в smoke: после прокрутки у каждой обёртки `getComputedStyle(el).transform === "none"`.
3. `will-change` вручную не ставится нигде, кроме пульсирующих огоньков карты (фаза 2). Motion управляет этим сам.
4. Карточки новостей и материалов держат полупрозрачный фон вместо `backdrop-filter` (решение `05-CONTEXT.md`). `backdrop-filter` остаётся у header, счётчиков и `GlassCard` формы, `StepCard`, триптиха, карточек ресурсов и панели.

## Reduced Motion Policy

Единый блок в `global.css`, ниже всех утилит. Раньше правила жили бы в пяти файлах, как в оригинале (шесть блоков `@media` в `orig-custom-styles.css`); фаза 5 сводит их в один и делает его единственным источником правды.

### Контракт разметки

Каждый декоративный анимированный слой несёт атрибут `data-anim` со значением из закрытого списка. Фаза 5 проставляет атрибуты там, где фазы 1–4 их не оставили.

| `data-anim` | Элемент | Владелец |
|-------------|---------|----------|
| `stars` | Слой звёздного поля в hero | Фаза 2 |
| `globe` | `<canvas>` глобуса | Фаза 2 |
| `beam` | `::before` кнопки `Button variant="primary"` (носитель атрибута сама кнопка) | Фаза 2 |
| `pulse` | Группа `<g>` пульсирующих огоньков | Фаза 2 |
| `new-light` | Кольцо нового огонька | Фаза 2, 3 |
| `particles` | Три псевдослоя частиц в `#resources` | Фаза 4 |
| `atmosphere` | Слой атмосферного зума карточки ресурсов | Фаза 4 |
| `wave` | Слой волн footer | Фаза 1 |
| `halo` | Гало footer | Фаза 1 |

### CSS

```css
@media (prefers-reduced-motion: reduce) {
  /* Страховка: ни одна незамеченная анимация не проигрывается */
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }

  /* Декоративные петли гасятся явно, конечный кадр не используется */
  [data-anim],
  [data-anim]::before,
  [data-anim]::after {
    animation: none !important;
  }

  /* Статичные конечные состояния */
  [data-anim="halo"] { transform: translateX(-50%); }
  [data-anim="pulse"] circle { transform: none; opacity: .9; }
  [data-anim="beam"]::before { background: var(--gradient-action); opacity: .55; }
  [data-anim="particles"] { opacity: .28; }

  /* Hover-движение выключено, смена цвета остаётся: это не движение */
  a:hover, button:hover, article:hover img { transform: none !important; }

  html { scroll-behavior: auto; }
}
```

Смена цвета, границы и тени при hover и focus остаются: WCAG требует убрать движение, а не обратную связь.

### JS

| Место | Что делает при reduce |
|-------|-----------------------|
| `Reveal`, `RevealGroup`, `RevealItem` | `useReducedMotion()` из `motion/react`, рендер без motion-обёртки, контент виден сразу |
| Fade текста hero | Тот же хук, `opacity: 1` без анимации |
| `GlobeCanvas` | rAF не запускается, рисуется один статичный кадр |
| `Starfield` | Мерцание выключено, точки статичны |
| `useCountUp` | Конечное значение сразу |
| Переход зума по чипу страны | `zoom.transform` без интерполяции, мгновенно |
| `scrollToSection` (фаза 1) | `behavior: "auto"`, флаг читается через `window.matchMedia` вне React-контекста |
| Панель ресурсов | Раскрывается мгновенно, фокус переносится так же |

Единственный источник флага внутри React: `useReducedMotion()`. Ручной `matchMedia` допускается только в `scrollToSection`, где хук недоступен.

### Проверка

- Playwright с `emulateMedia({ reducedMotion: "reduce" })` на 1440×900: все восемь секций видны без прокрутки до конца, `opacity` каждой обёртки равна 1, вертикальный размер документа отличается от обычного прогона не больше чем на 2%.
- Vitest `Reveal.test.tsx` с моком `matchMedia` на `(prefers-reduced-motion: reduce)`: контент в документе, у обёртки нет атрибута `style` с `opacity: 0`.
- Ручной прогон в системных настройках macOS «Уменьшить движение»: волны, гало, луч, частицы, пульс и глобус стоят.

## Responsive Checklist

### Правила измерения

| Проверка | Критерий |
|----------|----------|
| Горизонтальный скролл | `document.documentElement.scrollWidth <= window.innerWidth + 1` на каждой ширине, до и после прокрутки страницы до конца |

### 390 × 844

- Пилюля header отступает 12px от краёв, радиус 12px, скоса нет, бургер 48×48. Оверлей меню на весь экран, скролл `body` заблокирован, Esc закрывает, фокус возвращается на бургер.
- `Section` даёт `py-16 px-4`, контентная колонка равна 358px.
- Hero: H1 не выходит за колонку, глобус рисует меньше частиц, `devicePixelRatio` ограничен 2, canvas не создаёт горизонтальный скролл.
- Карта: счётчики стоят строкой над картой, а не абсолютом поверх неё; высота контейнера карты 520px; чипы переносятся в 3–4 ряда с зазором 8px; подсказка про два пальца видна и не наезжает на карту; `touch-action: pan-y` пропускает вертикальный скролл страницы.
- Форма: одна колонка, радио-карточки стеком, поля 54px, текст ошибки не сдвигает соседние поля.
- О проекте: `StepCard` стеком, видео-фасад во всю ширину с `aspect-ratio: 16 / 9`.
- Участие: триптих стеком, параллакса нет.
- Новости: одна колонка, обложка 4:5, кнопки пагинации не меньше 44×44.
- Ресурсы: стек «текст, затем три карточки», панель во всю ширину, сетка видео в 2 колонки, кнопка «Свернуть» доступна без горизонтального скролла.
- Цитата: силуэт карты обрезан контейнером, текст не уезжает под край.
- Footer: стек, ссылки с `padding-block: 8px`, юридическая строка не разрывается посреди слова.

### 768 × 1024

- Горизонтальное меню заменило бургер, пилюля отступает 16px, радиус 18px, скоса ещё нет.
- `Section` переходит на `py-24 px-8`.
- Новости в 2 колонки, форма в 2 колонки, `StepCard` ещё стеком (переключение на 1024).
- Ресурсы: 12-колоночная раскладка ещё не включена, карточки идут упорядоченной сеткой, панель не создаёт горизонтальный скролл.
- Счётчики карты либо строкой, либо поверх карты, в обоих случаях не перекрывают заголовок секции.

### 1024 × 900

- Скос пилюли 20° через `clip-path` виден, горизонтальный padding пилюли 32px.
- Счётчики стоят абсолютом поверх карты (`top: 88px`), не перекрывают ни заголовок, ни чипы.
- `StepCard` в 3 колонки, триптих в ряд, новости в 3 колонки.
- Ресурсы переходят на асимметричную 12-колоночную раскладку, отрицательные отступы карточек не выходят за границу секции.

### 1440 × 900

- Контент центрируется в 1152px, поля по 144px.
- Скошенные грани секции карты и декоративные слои с `inset: -8%` не создают горизонтальный скролл: секция-хост держит `overflow: hidden` (или `clip`), `body` держит `overflow-x: clip` как страховку.
- Карта занимает всю ширину секции, огоньки не выходят за пределы `viewBox`, зум колесом работает только с Ctrl/⌘.
- Вся страница совпадает по ритму секций с `docs/research/orig-full.jpeg`: скосы, стекло, градиенты на месте.

### 320px, дополнительно

Reflow по WCAG 1.4.10: при ширине 320px контент остаётся в одной колонке, горизонтальный скролл не появляется, ни один блок не обрезается. Проверка разовая, скриншот не обязателен.

### Защита от горизонтального скролла

| Приём | Где |
|-------|-----|
| `overflow-x: clip` на `body` | Не ломает `position: fixed` у header, в отличие от `overflow: hidden` |
| `overflow: hidden` на секциях с декоративными слоями | `#map`, `#involve`, `#resources`, `#quote`, `footer` |
| `max-width: 100%` на медиа | Обложки новостей, видео-фасады, SVG триптиха |
| `min-width: 0` на flex- и grid-детях | Чипы, поля формы, карточки: иначе длинное слово раздвигает колонку |

### aria по элементам

| Элемент | Атрибуты |
|---------|----------|
| Бургер | `aria-expanded`, `aria-controls`, `aria-label` «Открыть меню» / «Закрыть меню» |
| Оверлей меню | `role="dialog"`, `aria-modal="true"`, трап фокуса, возврат фокуса на бургер |
| Пункт активной секции | `aria-current="true"` |
| Карта | `role="img"` с `aria-label`, описывающим содержание: страны дивизиона и число огоньков |
| Счётчики | Число реальным текстом, контейнер `aria-live="polite"`, анимируемый span `aria-hidden="true"` рядом с visually-hidden итоговым значением |
| Чипы стран | `aria-pressed`, доступны с клавиатуры, «Весь дивизион» сбрасывает зум |
| Поля формы | `<label for>`, `aria-invalid` при ошибке, `aria-describedby` на текст ошибки, фокус на первое невалидное поле после submit |
| Тост | `role="status"`, текст «Ваш свет зажжён» читается без перехвата фокуса |
| Карточки ресурсов | `aria-expanded`, `aria-controls` на панель; панель `tabIndex={-1}` и получает фокус при открытии; Esc закрывает |
| Кнопка «Свернуть» | `aria-label` «Свернуть панель» |
| Видео-фасад | `<button>` с `aria-label` «Смотреть видео: {название}», постер с осмысленным `alt` или `alt=""` при дублирующей подписи |
| Пагинация новостей | `<nav aria-label="Страницы новостей">`, у стрелки `aria-label` «Следующая страница», текущая страница с `aria-current="page"` |
| Декоративная графика | SVG триптиха, звёзды, глобус, волны: `aria-hidden="true"` |
| Внешние ссылки | `target="_blank" rel="noopener noreferrer"`, в тексте ссылки понятно, куда она ведёт |

### Клавиатура

- Esc закрывает мобильное меню и панель ресурсов.
- Табом достижимы: skip-link, вордмарк, четыре пункта меню, кнопка hero, чипы стран, все поля формы, кнопка отправки, ссылки триптиха, карточки новостей, пагинация, три карточки ресурсов, содержимое панели, кнопка «Свернуть», видео-фасады, две ссылки footer.
- Карта управляется без мыши: чипы дают тот же результат, что зум и панорамирование.
- Ни одной ловушки фокуса, кроме оверлея меню, где она намеренная.
