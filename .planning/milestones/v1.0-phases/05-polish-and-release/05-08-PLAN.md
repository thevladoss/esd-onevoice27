## Phase Goal

Цель фазы из ROADMAP.md (дословно): «Секции лендинга плавно появляются при скролле, страница безупречно работает на всех целевых ширинах без ошибок в консоли, а финальный деплой подтверждён Playwright smoke-тестами».

<objective>
Закрыть дефект, найденный браузерным smoke плана 05-07: в верху страницы rAF идёт на 6–7 кадрах в секунду и на preview, и на проде. Замер на канвасе 1440×820 с синхронизацией `getImageData` показал: кадр `drawGlobe` с `shadowBlur: 12` на каждой шестой точке стоит 533 мс на GPU (Chrome, ANGLE Metal, Apple M4 Pro), тот же кадр без теней 4,2 мс, батчи по полосам широты 3,4 мс.

Purpose: подтвердить MOTION-02 (фоновые анимации не роняют кадр) и MOTION-04 (страница работает безупречно) на реальном железе; убрать риск пропуска reveal шапки карты при быстром скролле через hero.
Output: `drawGlobe` без `shadowBlur`, обновлённые тесты, повторный замер FPS на preview и проде в `docs/qa/SMOKE.md`.
</objective>
