# Feature Research

**Domain:** одностраничный лендинг-кампания общественного/церковного движения (campaign landing) с картой участия и формой присоединения
**Researched:** 2026-09-05
**Confidence:** HIGH (структура секций и эффекты подтверждены инлайн-CSS оригинала и снапшотами доступности в `docs/research/`)

## Как читать сложность

| Метка | Что значит |
|---|---|
| **S** | один компонент без состояния, CSS или разметка, до ~2 часов |
| **M** | компонент с состоянием, данными и тестами |
| **L** | подсистема: геометрия, canvas, контекст, несколько файлов |

Категории заданы для прототипа с замоканными данными на GitHub Pages, а не для продакшн-сайта кампании.

### Anti-Features (сознательно не делаем)

| Feature | Why Requested | Why Problematic | Alternative |
|---|---|---|---|
| Реальная отправка формы и бэкенд | «Форма же должна работать» | Прототип на статике; любой бэкенд тянет хостинг, персональные данные и согласия по закону | Замок в памяти страницы: тост, огонёк, счётчик +1; в UI честно не обещаем письмо |
| CMS и админка | Оригинал живёт на Hope Software CMS | Съест весь бюджет проекта, а показать надо редизайн | Типизированные моки в `src/data/*.ts` |
| Многоязычность | Оригинал англоязычный, ЕАД многонациональный | i18n-каркас удваивает работу над каждой строкой ради демо | Только русский; идентификаторы на английском |
| Карта на тайлах (Mapbox/MapLibre) | Так сделано в оригинале (react-map-gl) | Нужен токен, внешние тайлы, чужой стиль поверх фиолетовой темы, вес библиотеки | SVG на d3-geo + world-atlas: полный контроль над цветом и нулевые ключи |
| Пиксель-перфект копия | «Чтобы один в один» | Шрифт Figtree без кириллицы, исходного webm-глобуса нет, фото на CDN чужие; догонять 1:1 бесконечно | Цель «похоже и качественно»: те же токены, ритм и эффекты |
| Хотлинк фото с CDN ЕАД | Быстрее, чем рисовать | Чужой трафик, битые ссылки, авторские права | Локальная SVG/CSS-графика и YouTube-превью |
| Cookie-баннер и consent-гейт как в оригинале | «У них же есть» | Нам нечего трекать; гейт ломает демо ровно там, где показывают видео (на сайте ЕАД так и вышло) | Никакой аналитики, значит никакого баннера |
| Автоплей видео и звук | «Живее» | Раздражает, режет мобильный трафик, ломает reduced motion | Клик по обложке запускает плеер |
| 3D-глобус на three.js | Красивее canvas-точек | +500 КБ бандла и часы возни ради 40% высоты одного экрана | 2D-canvas: точки на сфере с проекцией и glow |
| Роутинг и `?page=2` для новостей | Так в оригинале (SSR-пагинация) | На GitHub Pages нет сервера, а History API ради 9 мок-новостей не нужен | Клиентская пагинация состоянием компонента |
| Бесконечный скролл новостей | Модно | Ломает доступ к футеру, где юридическая подпись | Пагинация 6 на страницу |
| Плеер официальной песни в секции «Музыка» | Карточка есть, хочется наполнить | Трека ЕАД нет, придумывать нельзя | Честная заглушка «официальная песня скоро» |
| Переключатель светлой темы | Привычка | Вся палитра построена на midnight-фоне, светлая тема ломает стекло и свечения | Только тёмная тема |
| Аналитика, пиксели, чат-виджет | «Для продакшна пригодится» | Внешние скрипты, ошибки в консоли, замедление; в ограничениях проекта только Google Fonts и YouTube | Ничего стороннего в рантайме |
| SSR / Next.js ради SEO | Оригинал на Next.js | GitHub Pages статичен, а прототип не индексируется как продукт | Vite SPA плюс мета-теги и Open Graph в `index.html` |
| Пиксельная «умная» кластеризация огоньков | 694 точки много | Для 694 точек преждевременно; сложность и баги на зуме | Рисуем все точки, пульсацию вешаем на группу |

### Dependency Notes

- **Счётчики требуют контекст огоньков:** число «694» должно быть длиной списка, а не константой в разметке, иначе после отправки формы счётчик и карта разойдутся.
- **Форма требует и контекст, и проекцию:** новый огонёк ставится по выбранной стране, значит генератор точки внутри границ страны нужен раньше формы. Порядок фаз: карта до формы.
- **Чипы стран требуют ту же проекцию, что и карта:** центрирование считается через `fitExtent` по границам страны из world-atlas, повторно использовать код рендера обязательно.
- **Три места используют один `VideoEmbed`:** «О проекте», новости и панель «Видео». Компонент делаем в фазе «О проекте» и переиспользуем.
- **Reveal-анимации конфликтуют с отсутствием JS и со скриншотами:** если стартовое состояние `opacity: 0`, а `whileInView` не сработал (ошибка, старый браузер, Playwright до прокрутки), секция останется невидимой. Использовать `once: true`, `amount: 0.2` и запасной класс, который выставляет `opacity: 1` при `prefers-reduced-motion`.
- **d3-zoom конфликтует со скроллом страницы:** на тач одним пальцем скроллим страницу, карту двигаем двумя. Оригинал на Mapbox показывает ровно эти подсказки («Use two fingers to move the map», «Use ⌘ + scroll to zoom the map»), значит делаем `zoom.filter` по числу касаний и по `ctrlKey/metaKey` для колеса.

## Доступность и мобильное поведение по каждому анимированному элементу

| Эффект | `prefers-reduced-motion: reduce` | Мобильное (≤767px) | Доступность |
|---|---|---|---|
| Canvas-глобус | RAF не запускаем, рисуем один статичный кадр | Меньше частиц, `dpr` не выше 2, пауза по `visibilitychange` и когда canvas вне вьюпорта | `aria-hidden="true"`, декоративный, смысл дублирует H1 |
| Звёздное поле | Без мерцания, статичные точки | Плотность ниже, слой можно выключить | `aria-hidden="true"` |
| Луч по границе кнопки | `animation: none`, оставляем статичный градиент | Без изменений, эффект дешёвый | Видимый `outline: 2px solid; outline-offset: 4px` на `:focus-visible`, как в оригинале |
| Count-up счётчиков | Сразу конечное значение, без анимации | Без изменений | Число как реальный текст в DOM; анимируемый span `aria-hidden="true"`, рядом visually-hidden с итоговым значением, контейнер `aria-live="polite"` для обновления после формы |
| Пульсация огоньков | Статичное свечение без пульса | Анимируем группу (`<g>`), не каждую из 694 точек | Карта `role="img"` с текстовым описанием; данные доступны через счётчики и чипы стран |
| Зум и панорамирование карты | Не влияет, но переход к стране без tween | Cooperative gestures: один палец скроллит страницу, два двигают карту; подсказка текстом под картой | Кнопки «+», «−», «Сбросить» с клавиатуры; чипы стран дают тот же результат без мыши |
| Reveal секций | Показываем сразу, без сдвига и без stagger | Те же пороги, `amount: 0.2`, `once: true` | Контент обязан быть виден при сбое JS; порядок в DOM совпадает с визуальным |
| Параллакс триптиха | `separation: 0`, `opacity: 1`, тени и glow в 0 (так и в оригинале) | Ниже 768px вертикальный стек без параллакса | Ссылки внутри карточек остаются обычными `<a>` с якорями |
| Hover-зум обложек новостей | `transform: none`, `transition: none` | Гейт `@media (hover: hover) and (pointer: fine)`, на тач эффекта нет | Вся карточка ссылка, фокус подсвечивает рамку |
| Атмосферный зум и частицы ресурсов | `animation: none` | Без изменений | Декоративные слои `aria-hidden` |
| Дрейф волн футера | `animation: none`, гало возвращаем в `translateX(-50%)` (правило из оригинала) | Без изменений | Декоративно |
| Открытие панели ресурсов | Без анимации высоты, мгновенно | Панель на всю ширину под сеткой, автоскролл к ней | `aria-expanded` и `aria-controls` на карточке, фокус переносим на заголовок панели |
| Бургер-меню | Без slide, только показ | Полноэкранный оверлей, `overflow: hidden` на body | Focus trap, закрытие по Esc и по клику вне, `aria-expanded` на кнопке |
| Тост после отправки формы | Без анимации входа | Позиция снизу, не перекрывает кнопку | `role="status"`, `aria-live="polite"`, автоскрытие не раньше 5 секунд |
| Смена страницы новостей | Без кросс-фейда | Пагинация крупными тап-таргетами от 44px | Кнопки, а не ссылки; `aria-current="page"` на активной |

## MVP Definition

### Launch With (v1)

Прототип, который можно показать заказчику по ссылке.

## Competitor Feature Analysis

| Feature | onevoice27.org (оригинал) | esd.onevoice27.org + esd-map.vercel.app | Наш подход |
|---|---|---|---|
| Карта | Mapbox через react-map-gl, токен, тайлы | Отдельное приложение на Vercel, уводит с лендинга | SVG на d3-geo прямо в секции лендинга, без токенов |
| Счётчики | People 4 268 / Groups 1 150 поверх карты | 694 человека / 248 групп в отдельном приложении | Те же числа ЕАД, count-up при появлении, растут после формы |
| Форма | Имя, фамилия, адрес (combobox), email, согласие, отправка на бэкенд | Имя, фамилия, email, телефон, страна, город на esd-map | Поля оригинала плюс страна и город, без телефона; отправка замокана |
| Hero-визуал | webm-глобус + canvas-частицы, `mix-blend-mode: screen` | Заголовок поверх стоковой фотографии | Canvas-частицы без видео |
| Видео | Один встроенный ролик, закрыт cookie-гейтом | 16 роликов, все закрыты гейтом «Accept YouTube» | Фасад с обложкой, клик грузит `youtube-nocookie` |
| Новости | 6 карточек, серверная пагинация `?page=2` со ссылками на adventist.news | Раздела нет | 9 мок-новостей ЕАД, клиентская пагинация |
| Ресурсы | Три карточки с панелями Music / Materials / Video | Кнопки «Скачать материалы» и SharePoint | Три карточки и панели с реальными ссылками ЕАД, музыка заглушкой |
| Анимации | CSS `@keyframes` + IntersectionObserver + CSS-переменные из JS | Декоративная сфера и статика | `motion` для reveal, CSS `@keyframes` для фоновых петель |
| Reduced motion | Пять отдельных блоков `@media (prefers-reduced-motion: reduce)` по секциям | Не проверялось | Тот же принцип плюс `useReducedMotion` в React-эффектах |
| Cookie-баннер | Есть, блокирует видео и карту | Есть, блокирует все 16 роликов | Не делаем: нечего трекать |

## Открытые вопросы

- Тексты трёх карточек 1/2/3 и триптиха переводим с английского оригинала сами; официального русского перевода в снапшоте ЕАД нет (LOW confidence по формулировкам, не по структуре).
- Иллюстрации триптиха в оригинале фотографические (`<figure>` в снапшоте). Насколько убедительно их заменит SVG-графика, покажет только визуальный прогон.
- Девять новостей ЕАД придуманы: заголовки и даты нужно согласовать, чтобы прототип не выглядел как фейковые новости церкви.
- Распределение 694 огоньков по 12 странам берём пропорционально, реальных данных по странам нет.
