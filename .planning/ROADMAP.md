# Roadmap: Единый голос 27 — лендинг ЕАД (редизайн)

## Overview

Прототип идёт от голого каркаса до полностью живого лендинга уровня оригинала onevoice27.org. Сначала встаёт инфраструктура и деплой на GitHub Pages, чтобы риски base path и прав Actions снялись сразу. Дальше собирается самая рискованная и самая заметная часть — hero с canvas-глобусом и карта дивизиона с огоньками. От неё расходятся два независимых контентных потока: конверсионный (форма, о проекте, участие) и информационный (новости, ресурсы, цитата). Завершает работу фаза полировки — reveal-анимации, адаптив, доступность и финальный прогон Playwright перед последним деплоем.

## Phases

**Phase Numbering:**
- Integer phases (1, 2, 3): Planned milestone work
- Decimal phases (2.1, 2.2): Urgent insertions (marked with INSERTED)

Decimal phases appear between their surrounding integers in numeric order.

- [ ] **Phase 1: Каркас и деплой** - Header, footer, токены стиля и CI/CD с первым живым деплоем на GitHub Pages
- [ ] **Phase 2: Hero и карта** - Canvas-глобус, градиентный CTA и SVG-карта ЕАД с огоньками, счётчиками и чипами стран
- [ ] **Phase 3: Форма, О проекте, Участие** - Форма «зажечь свет» с обратной связью на карту, секции «Что такое Единый голос 27?» и «От убеждения к действию»
- [ ] **Phase 4: Новости, Ресурсы, Цитата** - Лента новостей с пагинацией, раскрывающиеся панели ресурсов и цитата из «Евангелизма»
- [ ] **Phase 5: Полировка и финальный прогон** - Reveal-анимации, мобильный аудит, чистая консоль и финальная проверка Playwright перед деплоем

## Phase Details

### Phase 1: Каркас и деплой
**Goal**: Посетитель открывает опубликованный на GitHub Pages лендинг с рабочим header, footer и визуальным языком оригинала, а каждый пуш в main автоматически прогоняет тесты, билд и деплой
**Mode:** mvp
**Depends on**: Nothing (first phase)
**Requirements**: SHELL-01, SHELL-02, SHELL-03, SHELL-04, SHELL-05, SHELL-06, QA-03
**Success Criteria** (what must be TRUE):
  1. Посетитель видит плавающий header-пилюлю с логотипом «Единый голос 27 / Миссия для всех» и меню из четырёх якорей; на мобильном меню сворачивается в бургер, открывается и закрывается кнопкой и клавишей Esc, блокирует скролл и возвращает фокус
  2. Клик по пункту меню плавно прокручивает страницу к соответствующей (пока пустой) секции с учётом высоты header
  3. Посетитель видит footer с дрейфующими волнами, подписью «Официальный сайт Церкви христиан адвентистов седьмого дня», строкой «© 2026 Евро-Азиатский дивизион» и ссылками на esd.adventist.org и onevoice27.org
  4. Вся страница оформлена токенами палитры оригинала, шрифтами Onest/Noto Sans и стеклянными карточками; index.html отдаёт lang="ru", корректный title, описание и Open Graph теги
  5. Сайт доступен по адресу https://thevladoss.github.io/esd-onevoice27/, а GitHub Actions прогоняет npm ci, npm test и npm run build перед каждым деплоем dist в main

### Phase 2: Hero и карта
**Goal**: Посетитель видит эффектный hero с вращающимся глобусом и кнопкой «Зажечь свой свет», а ниже — живую карту ЕАД с огоньками, счётчиками и переключением стран
**Mode:** mvp
**Depends on**: Phase 1
**Requirements**: HERO-01, HERO-02, HERO-03, MAP-01, MAP-02, MAP-03, MAP-04, MAP-05, MAP-06, QA-01
**Success Criteria** (what must be TRUE):
  1. Посетитель видит надзаголовок «Единое глобальное движение», градиентный H1 «Вместе, единым голосом» и подзаголовок, а справа вращается canvas-глобус из частиц, который останавливается при prefers-reduced-motion, скрытой вкладке и вне вьюпорта
  2. Кнопка «Зажечь свой свет» ведёт на #light-form и показывает вращающийся луч по границе (или статичную заливку без анимации при reduced motion)
  3. Посетитель видит секцию со скошенными краями и SVG-картой 12 стран ЕАД без разрыва России на антимеридиане, на которой пульсируют замоканные огоньки людей и групп (не более 40 одновременно)
  4. Счётчики «Человек» и «Групп» показывают отформатированные значения (`4 268`) с анимацией счёта при первом появлении (мгновенно при reduced motion), а чипы стран и «Весь дивизион» с клавиатуры и мышью центрируют карту на выбранной стране
  5. Посетитель может зумить и панорамировать карту колесом с Ctrl/⌘, перетаскиванием и жестами на touch, не теряя обычный скролл страницы; Vitest-тесты подтверждают детерминизм генератора огоньков, форматирование чисел и редьюсер огоньков

### Phase 3: Форма, О проекте, Участие
**Goal**: Посетитель понимает суть проекта, видит путь «от убеждения к действию» и может зажечь свой свет через форму, результат которой сразу отражается на карте и в счётчиках
**Mode:** mvp
**Depends on**: Phase 2
**Requirements**: FORM-01, FORM-02, FORM-03, ABOUT-01, ABOUT-02, ABOUT-03, INVOLVE-01
**Success Criteria** (what must be TRUE):
  1. Посетитель выбирает тип «Индивидуальный свет» или «Групповой маяк», заполняет имя, фамилию, страну (из 12 стран ЕАД), город, email и чекбокс согласия; ошибки валидации показаны понятным текстом на русском
  2. После успешной отправки появляется тост role="status" «Ваш свет зажжён», на карте в выбранной стране появляется новый огонёк, соответствующий счётчик увеличивается на 1, форма сбрасывается, а запрос никуда не отправляется
  3. Посетитель читает раздел «Что такое Единый голос 27?» с абзацем о сентябре 2027 и 2000-летии крещения Иисуса, видит обложку YouTube-ролика и запускает встроенное видео по клику
  4. Посетитель видит три стеклянные карточки «1 Проект / 2 Подготовка / 3 Цель» и триптих «Личное преображение / Материалы для церкви / Делиться» со ссылками-действиями на соответствующие секции; component-тесты подтверждают добавление огонька на карту и рост счётчика при отправке формы

### Phase 4: Новости, Ресурсы, Цитата
**Goal**: Посетитель просматривает новости ЕАД, находит нужные материалы через раскрывающиеся панели ресурсов и читает цитату из «Евангелизма»
**Mode:** mvp
**Depends on**: Phase 2 (независима от Phase 3, может выполняться параллельно)
**Requirements**: NEWS-01, NEWS-02, RES-01, RES-02, RES-03, RES-04, QUOTE-01
**Success Criteria** (what must be TRUE):
  1. Посетитель видит сетку из 9 мок-новостей ЕАД с обложками из YouTube-превью, датой и заголовком, и листает их постранично (по 6 на страницу, кнопки 1, 2, стрелка) без перезагрузки страницы
  2. Посетитель кликает по одной из асимметричных карточек Музыка / Материалы / Видео — под сеткой раскрывается панель: «Материалы» показывает 5 позиций со ссылками на реальные страницы ЕАД, «Видео» — 16 роликов как фасады с обложкой и lite-embed по клику, «Музыка» — честную заглушку «Официальная песня скоро»
  3. Повторный клик по активной карточке сворачивает панель; открытие и закрытие панелей доступно с клавиатуры через aria-expanded и aria-controls
  4. Посетитель читает цитату из «Евангелизма», стр. 122, на градиентном фоне с силуэтом карты и подписью источника

### Phase 5: Полировка и финальный прогон
**Goal**: Секции лендинга плавно появляются при скролле, страница безупречно работает на всех целевых ширинах без ошибок в консоли, а финальный деплой подтверждён Playwright smoke-тестами
**Mode:** mvp
**Depends on**: Phase 3, Phase 4
**Requirements**: MOTION-01, MOTION-02, MOTION-03, MOTION-04, QA-02, QA-04
**Success Criteria** (what must be TRUE):
  1. Секции и карточки появляются при скролле через motion (whileInView, stagger) один раз, а при prefers-reduced-motion весь контент виден сразу; фоновые CSS-анимации (луч кнопки, частицы ресурсов, волны и гало футера, пульсация огоньков) отключаются вместе с ним
  2. Страница выглядит и работает без горизонтального скролла на 390, 768, 1024 и 1440px, все интерактивные элементы имеют видимый фокус и aria-атрибуты, а в консоли собранного билда нет ошибок и 404
  3. Component-тесты дополнительно покрывают навигацию header и чипы стран (в дополнение к форме и панелям ресурсов, проверенным в фазах 2–4)
  4. Сайт на https://thevladoss.github.io/esd-onevoice27/ совпадает с локальным vite preview, а Playwright smoke подтверждает наличие всех секций и чистую консоль на 1440 и 390px
