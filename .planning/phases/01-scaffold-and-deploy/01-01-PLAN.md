## Phase Goal

**Как** посетитель, **я хочу** открыть опубликованный на GitHub Pages лендинг с рабочим header, footer и визуальным языком оригинала, **чтобы** с первого экрана узнавать «Единый голос 27» и переходить к разделам по меню, пока каждый пуш в main сам прогоняет тесты, билд и деплой.

История переписана из строки `**Goal:**` фазы 1 в ROADMAP.md один к одному, без расширения объёма (в ROADMAP цель сформулирована прозой, а не в каноническом формате «As a / I want to / so that»).

<objective>
Поднять «ходячий скелет» проекта: скаффолд Vite 8 + React 19 + TypeScript 5.9 + Tailwind CSS v4 + Vitest 5, контракты дизайн-системы (tokens.css, global.css, copy.ts, Wordmark, SkipLink), финальную композицию `App.tsx` с восемью секциями-заглушками, jsdom-моки и первый тест, GitHub Actions workflow и первый живой деплой на https://thevladoss.github.io/esd-onevoice27/.

Purpose: снять сразу главные риски фазы (base path, Tailwind v4, права deploy-pages, совместимость Vite 8) и зафиксировать файлы-контракты, чтобы планы 01-02, 01-03 и 01-04 шли параллельно, не трогая `App.tsx`, `main.tsx`, `index.html`, `global.css`, `tokens.css`, `copy.ts`, `setup.ts` и `package.json`.

Output: рабочий проект в корне репозитория, зелёные `npm test` и `npm run build`, README на русском, workflow `deploy.yml`, успешный прогон в GitHub Actions и ответ 200 с живого URL.
</objective>
