# Phase 3 — UI Design Contract

> Визуальный и интеракционный контракт фазы «Форма, О проекте, Участие». Автор: gsd-ui-researcher, проверяет gsd-ui-checker.

**Секции фазы:** `#light-form` (FORM-01, FORM-02, FORM-03), `#about` (ABOUT-01, ABOUT-02, ABOUT-03), `#involve` (INVOLVE-01).

**Правило фазы:** дизайн-систему задаёт фаза 1. Токены палитры, шрифты, `Section`, `Eyebrow`, `GradientTitle`, `Button`, `GlassCard` берутся как есть. Фаза 3 добавляет только локальные токены формы, карточек шагов и триптиха, перечисленные ниже.

## Design System

## Typography

| Role | Size | Weight | Line Height | Где |
|------|------|--------|-------------|-----|
| Body | 16px | Noto Sans 400 | 1.6 | Абзацы секций, описания радио-карточек, пункты списков, значения полей, текст согласия, итоговая фраза карточки шага |
| Label | 14px | Noto Sans 700 | 1.35 | Подписи полей («Имя», «Фамилия», «Страна», «Город», «Email»), заголовок группы «Тип света» |
| Heading | 24px | Onest 800 | 1.15 | Заголовки карточек шагов («Проект», «Подготовка», «Цель»), заголовки карточек триптиха, заголовок радио-карточки |
| H2 секций (наследуется) | `--text-section` = clamp(30px, 4vw, 48px) | Onest 900, letter-spacing -0.035em | 1.05 | H2 «Зажгите свой свет», «Что такое Единый голос 27?», «От убеждения к действию» рендерятся `GradientTitle variant="section"` из фазы 1 без переопределений (см. 01-UI-SPEC.md, роль Heading/`--text-section`, обновлено до Onest 900 / 30–48px 2026-09-05); отдельной роли Display в фазе 3 нет |

**Исключения (три, каждое обосновано):**

| Значение | Где | Причина |
|----------|-----|---------|
| 12px / Noto Sans 700 / uppercase / letter-spacing .1em | `Eyebrow` секций и ссылки-действия триптиха | Примитив `Eyebrow` задан фазой 1; ссылки триптиха повторяют его типографику по 03-CONTEXT.md |
| 13px / Noto Sans 400 / 1.35 | Текст ошибки валидации под полем | Зафиксировано в 03-CONTEXT.md, чтобы ошибка не спорила с label |
| 56px / Onest 900 / 1 | Номер карточки шага (1, 2, 3) | Декоративный элемент с градиентной заливкой текста, единственное применение веса 900 в фазе |

**Гарнитуры и веса:** Onest использует 800 (заголовки) и 900 (только номера шагов). Noto Sans использует 400 (текст) и 700 (подписи, микротекст, кнопка). Больше весов фаза не вводит.

**Правила набора:**
- `text-wrap: balance` на H2 и заголовках карточек.
- `font-variant-numeric: lining-nums tabular-nums` на номерах шагов.
- Абзацы секций ограничены `max-width: 42rem`, текст карточек по ширине карточки.
- Ошибки валидации и микротекст не переносят регистр: пишутся строчными, uppercase остаётся у `Eyebrow` и ссылок-действий.

## Color

Палитра фазы 1, без новых оттенков.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-midnight-950` `#070210` (форма), `--color-midnight-900` `#120c34` (о проекте, участие) | Фон секций, глубина под стеклом |
| Secondary (30%) | `.glass`: `linear-gradient(145deg, rgb(48 63 131 / .86), rgb(18 12 52 / .76))`, border `rgba(184,192,230,.22)`, radius 16px, `--shadow-card` | Контейнер формы, карточки шагов, карточки триптиха, панель тоста |
| Accent (10%) | Градиент бренда `linear-gradient(125deg, #6c2c68 0%, #3b4da1 50%, #39727e 100%)` и его сплошная форма `--color-horizon-400` `#7bc2c7` | См. список ниже |
| Destructive | `#fca5a5` | Только текст ошибки валидации и `aria-invalid` рамка поля. Деструктивных действий в фазе нет |

**Accent зарезервирован под (закрытый список):**
1. Кнопка `Зажечь свой свет →` (заливка градиентом бренда, примитив `Button variant="primary"`).
2. Рамка и точка-индикатор выбранной радио-карточки: рамка `rgb(123 194 199 / .72)`, фон `rgb(84 164 172 / .16)`, точка `--color-signal-400` `#bb6cae` для «Индивидуальный свет» и `--color-horizon-400` `#7bc2c7` для «Групповой маяк».
3. Рамка поля в фокусе `rgb(123 194 199 / .46)` и кольцо фокуса `--color-horizon-200` `#aad9dc`.
4. Кнопка play видео-фасада (круг 72px с градиентом `#6c2c68 → #3b4da1`).
5. Акцентная линия сверху слева карточки шага: `linear-gradient(90deg, transparent, #bb6cae 28%, #7bc2c7 62%, transparent)`.
6. Маркеры списков карточек шагов: `--color-signal-300` `#d28ebe`.
7. Градиентная линия под ссылкой-действием триптиха: `linear-gradient(90deg, #bb6cae, #7bc2c7, transparent)`.
8. Иконка галочки в тосте успеха.

Ни один другой интерактивный элемент акцент не использует: ссылки в тексте, чекбокс в невыбранном состоянии и рамки карточек остаются на `paper` с прозрачностью.

**Текст и прозрачности:**

| Роль | Значение |
|------|----------|
| Основной текст | `--color-paper` `#f8f7fb` при 0.94 |
| Приглушённый текст (описания, пункты списков) | `rgb(248 247 251 / .8)` |
| Плейсхолдер поля | `rgb(248 247 251 / .56)` |
| Разделитель карточки шага | `linear-gradient(90deg, rgb(217 222 244 / .55), rgb(248 247 251 / .32) 30%, rgb(248 247 251 / .16))` |
| Шов между карточками триптиха | `rgb(248 247 251 / .12)` |

**Контраст:** `#f8f7fb` на `#070210` даёт 18.9:1, `rgb(248 247 251 / .8)` на стекле остаётся выше 7:1, `#fca5a5` на `rgb(18 12 52 / .58)` выше 7:1. Требование WCAG AA выполняется с запасом.

## Interaction Contract

### Радио-карточки типа света

| Состояние | Оформление |
|-----------|-----------|
| default | Фон `--option-surface`, border 1px `--option-border`, radius 16px, padding 16px, курсор pointer |
| hover (`@media (hover: hover)`) | border `rgb(123 194 199 / .4)`, transition `--ui-transition` |
| checked | border `--option-border-active`, фон `--option-surface-active`, точка-индикатор 12px в правом верхнем углу: `#bb6cae` для индивидуального, `#7bc2c7` для группового |
| focus-visible | Кольцо `2px solid var(--focus-ring)`, `outline-offset: 3px` на всей карточке |

- Разметка: `fieldset` с `legend` «Тип света» (визуально как Label 14px/700), внутри два `label`, каждый содержит `input[type="radio"]` в классе `sr-only` и текст.
- Оформление через `:has(input:checked)` и `:has(input:focus-visible)`, без JS-классов.
- Клавиатура работает нативно: Tab входит в группу, стрелки переключают вариант.
- Значение по умолчанию: `individual` (карточка выбрана при загрузке, форма никогда не остаётся без типа).

### Поля ввода и select

| Состояние | Оформление |
|-----------|-----------|
| default | Высота 54px, padding `0 16px`, radius `--field-radius`, фон `--field-surface`, border 1px `--field-border`, текст `rgb(248 247 251 / .94)` |
| hover | border `rgb(123 194 199 / .3)` |
| focus | border `--field-border-focus`, фон `--field-surface-focus`, кольцо `2px solid var(--focus-ring)`, `outline-offset: 2px` |
| invalid | border `--field-error`, `aria-invalid="true"`, текст ошибки под полем через `aria-describedby` |
| placeholder | `--field-placeholder` |

- `select` использует нативный список опций (`option` с фоном `#120c34` и цветом `#f8f7fb`), первая опция `value=""` с текстом «Выберите страну», собственная стрелка справа 16px, `appearance: none`.
- Чекбокс согласия: нативный `input` в `sr-only`, кастомный бокс 20px с radius 6px, галочка SVG появляется при `:checked`, вся строка `label` кликабельна и держит высоту не менее 44px.
- Автозаполнение: `autocomplete="given-name" | "family-name" | "country-name" | "address-level2" | "email"`.

### Валидация

| Правило | Сообщение |
|---------|-----------|
| Имя короче 2 символов | «Введите имя» |
| Фамилия короче 2 символов | «Введите фамилию» |
| Страна не выбрана | «Выберите страну» |
| Город короче 2 символов | «Укажите город» |
| Email не проходит `^[^\s@]+@[^\s@]+\.[^\s@]+$` | «Введите корректный email» |
| Согласие не отмечено | «Нужно согласие на обработку данных» |

- Первая проверка запускается на submit. После первой неудачной попытки поле проверяется повторно на `blur` и очищает ошибку сразу, как только значение становится валидным.
- Фокус переходит на первое невалидное поле после submit.
- Ошибки не появляются во время первого набора текста: пользователь не видит красного, пока не нажал кнопку.

### Отправка и тост

- Кнопка: `Button variant="primary"`, на всю ширину, текст «Зажечь свой свет →».
- Во время отправки (1200ms): текст «Зажигаем…», `aria-busy="true"`, `disabled`, непрозрачность 0.72, курсор `progress`. Повторный клик исключён.
- Успех: вызов `addLight({ type, countryId })`, сброс полей, тип света остаётся выбранным, фокус возвращается на кнопку.
- Тост: `role="status"`, `aria-live="polite"`, фиксирован снизу по центру, `bottom: 24px`, `z-index: 60` (над плавающим header фазы 1), `GlassCard` с padding `16px 20px`, `max-width: 26rem`, иконка-галочка 20px в круге градиента бренда, текст «Ваш свет зажжён! Огонёк уже на карте.» 16px/400.
- Появление: `opacity 0 → 1`, `translateY(12px) → 0`, 240ms `--ui-transition`. Уход: 200ms, `opacity → 0`. Автозакрытие через 4000ms, закрытие по клику в любую точку тоста, кнопка закрытия не нужна.
- Сеть не используется: `<form onSubmit>` вызывает `preventDefault`, у формы нет `action` и `method`.

- Если постер не загрузился: `onError` показывает градиентную заглушку `linear-gradient(140deg, #211a3e, #303f83)` с названием ролика 16px по центру. Кнопка play остаётся работать.

### Карточка шага

- Стекло `GlassCard`, `position: relative`, `isolation: isolate`.
- `::after`: линия 96px × 1px, `top: 0; left: 24px`, градиент акцента, `opacity: .76`.
- `::before`: `inset: 0`, `linear-gradient(145deg, rgb(255 255 255 / .035), transparent 36%)`, внутренние тени `inset 1px 1px 0 rgb(255 255 255 / .06)` и `inset -1px -1px 0 rgb(7 2 16 / .4)`, `opacity: .58`.
- Разделитель: `hr` высотой 1px, ширина 34%, градиент разделителя, `transform-origin: left`.
- Hover (`@media (hover: hover) and (pointer: fine)`): border `rgba(184,192,230,.34)`, `::after` `opacity: 1`, `::before` `opacity: 1`, `hr` расширяется до 100%, transition `--ui-transition`.
- Карточка не кликабельна и не получает фокус: это контент, не элемент управления.

### Карточка триптиха

- Медиа: `aspect-ratio: 4 / 3`, `overflow: hidden`, SVG `preserveAspectRatio="xMidYMid slice"`, `filter: saturate(var(--triptych-media-saturation))`, поверх `linear-gradient(180deg, transparent 45%, rgb(7 2 16 / .55))`.
- Hover (`@media (hover: hover)`): SVG `scale(1.025)`, `saturate(1)`, подчёркивание ссылки растёт `scaleX(.34) → scaleX(1)`, transition `--ui-transition`.
- Ссылка-действие: uppercase Noto Sans 700 12px, letter-spacing .1em, стрелка `→` через отдельный `<span aria-hidden="true">`, градиентная линия под текстом (`::before`, высота 1px, `bottom: 5px`).
- `focus-visible` на ссылке: кольцо `2px solid var(--focus-ring)`, `outline-offset: 4px`, radius 4px. Подчёркивание раскрывается до 100% и при фокусе, не только при hover.
- Область клика ограничена ссылкой, вся карточка кликом не перехватывается (иначе три вложенные цели ломают навигацию с клавиатуры).

## Motion Contract

| Что | Длительность | Кривая | При `prefers-reduced-motion: reduce` |
|-----|--------------|--------|--------------------------------------|
| Hover карточек шагов и триптиха, рост подчёркивания, разделитель | 420ms | `cubic-bezier(0.32, 0.72, 0, 1)` | `transition: none`, конечное состояние по hover остаётся |
| Появление тоста | 240ms | та же | Появляется без сдвига и без прозрачности, сразу видим |
| Уход тоста | 200ms | `ease` | Исчезает мгновенно |
| Смена состояния поля (border, фон) | 180ms | `ease` | `transition: none` |
| Кнопка play при hover | 420ms | та же | `transition: none` |

- Автозакрытие тоста через 4000ms работает при любом режиме движения: это таймер, не анимация.
- Reveal-анимации секций при скролле фаза 3 не добавляет: `whileInView` и stagger приходят в фазе 5 (MOTION-01). Разметка не должна мешать их подключению, поэтому каждая карточка остаётся отдельным узлом верхнего уровня внутри своего контейнера.

## Accessibility Contract

| Требование | Реализация |
|------------|------------|
| Все поля подписаны | `<label for>` на каждое поле, `fieldset` + `legend` для группы типа света |
