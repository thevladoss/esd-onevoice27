    `fibonacciSphere(n)`: `phi = Math.PI * (3 - Math.sqrt(5))`; для i в 0..n-1: `y = 1 - (i / (n - 1)) * 2`, `r = sqrt(1 - y*y)`, `theta = phi * i`, `x = cos(theta) * r`, `z = sin(theta) * r`; результат `Float32Array(n * 3)`.
    `latitudeColor(y)`: кусочно-линейная интерполяция в RGB: для `y >= 0` между `#3b4da1` (y=0) и `#d28ebe` (y=1), для `y < 0` между `#3b4da1` и `#7bc2c7` (y=-1); компоненты округлять `Math.round`, формат `rgb(r, g, b)`.
    `shouldAnimate(f)`: `f.inView && !f.hidden && !f.reducedMotion`.
    `globeLayout(w, h)`: при `w < 768` центр `(0.5 * w, 0.38 * h)`, `r = min(w, h) * 0.40`; иначе центр `(0.72 * w, 0.46 * h)`, `r = min(w, h) * 0.46` (UI-SPEC: глобус до 768px уходит в центр).

Использовать `ctx.globalAlpha` для alpha, вернуть в 1 в конце.
