# Phase 2 — UI Design Contract

> Визуальный и интеракционный контракт фазы «Hero и карта». Источник истины для планировщика и исполнителя. Составил gsd-ui-researcher, проверяет gsd-ui-checker.

**Границы фазы:** hero (звёздное поле, canvas-глобус, градиентный H1, CTA с вращающимся лучом) и секция карты (скошенные края, SVG-карта ЕАД на d3-geo, огоньки двух цветов, стеклянные счётчики с count-up, чипы стран, зум и панорамирование).

**Дизайн-систему задаёт фаза 1.** Токены, шрифты и примитивы (`Section`, `Eyebrow`, `GradientTitle`, `Button`, `GlassCard`, `.glass`) фаза 2 переиспользует и не переопределяет. Новые значения ниже помечены как «фаза 2».

## Design System

| Property | Value |
|----------|-------|
| Tool | none (дизайн-система собрана вручную на Tailwind v4 `@theme`) |
| Preset | not applicable |
| Component library | собственные примитивы фазы 1 в `src/components/layout/` |
| Icon library | не используется: индикаторы счётчиков рисуются CSS-кругами, огоньки это SVG `<circle>` |
| Font | Onest (display, 900) и Noto Sans (body, 400/700), Google Fonts, `display=swap` |

**Почему не shadcn.** Фаза 1 зафиксировала собственные примитивы поверх Tailwind v4 `@theme` и палитру оригинала onevoice27.org. shadcn притащил бы Radix, `cn()`, `class-variance-authority` и свою систему цветов ради пяти компонентов, которые уже написаны. Инициализация ломала бы locked-решения фазы 1. Гейт закрыт решением «none», сторонние реестры в проекте не используются.

| sm | 8px | зазор между чипами по горизонтали и вертикали |
| md | 16px | внутренний padding счётчика, зазор между счётчиками, inset подсказки о жестах |
| lg | 24px | eyebrow до H2 карты, подзаголовок hero до CTA, `fitExtent` padding карты |
| xl | 32px | заголовок секции карты до чипов, чипы до контейнера карты |
| 2xl | 48px | внутренний отступ hero по горизонтали на широких экранах (верх clamp) |
| 3xl | 64px | вертикальный padding секции карты на мобильном (`py-16`) |
| 4xl | 96px | вертикальный padding секции карты от 768px (`md:py-24`) |

**Исключения (перечислены полностью, других нет):**

| Значение | Где | Почему не кратно 4 |
|----------|-----|--------------------|
| 46px | глубина скоса секции карты (`clip-path`) | зафиксировано в CONTEXT, декоративная геометрия, не отступ |
| 88px | `top` блока счётчиков над картой на десктопе | зафиксировано в CONTEXT, кратно 8, лежит в шкале |

| clamp-выражения | высота hero, высота карты, размеры H1 и H2 | адаптивные размеры, границы шкалы соблюдены |

## Typography

Четыре роли, две ступени веса в body-семействе (400 и 700). Display-семейство Onest используется в единственном начертании 900. Больше весов фаза не вводит.

| Role | Size | Weight | Line Height | Где |
|------|------|--------|-------------|-----|
| Display | mobile `clamp(2.75rem, 8vw, 4.5rem)`, от 1024px `clamp(3.75rem, 5.4vw, 5.5rem)` | Onest 900 | 0.94 | H1 hero «Вместе, единым голосом» |
| Heading | `clamp(1.875rem, 4vw, 3rem)` (30px до 48px) | Onest 900 | 1.05 | H2 «Зажигаем свет по всему дивизиону», числа счётчиков (`clamp(3.5rem, 9vw, 4.5rem)`, та же роль) |
| Body | `clamp(1rem, 1.8vw, 1.2rem)` (16px до 19.2px) | Noto Sans 400 | 1.65 | подзаголовок hero, описание под H2, подсказка о жестах (фиксированные 12px) |
| Label | 12px | Noto Sans 700 | 1.4 | eyebrow, подписи счётчиков, чипы стран, надпись на CTA (14px, та же роль) |

> **Согласовано с фазой 1 (2026-09-05).** Onest 900 для H2 секции и чисел счётчиков разрешён контрактом фазы 1 (пункты 4–5 списка «Насыщенность 900 разрешена»): `GradientTitle variant="section"` теперь `--text-section = clamp(1.875rem, 4vw, 3rem)`, Onest 900, letter-spacing -0.035em, line-height 1.05. H2 «Зажигаем свет по всему дивизиону» рендерится этим примитивом без локальных переопределений.

**Трекинг:**

| Роль | letter-spacing |
|------|----------------|
| Display | -0.055em |
| Heading (H2) | -0.035em |
| Heading (число счётчика) | -0.02em, `font-variant-numeric: tabular-nums` |
| Body | 0 |
| Label / eyebrow | 0.10em, uppercase |
| Label / чип и CTA | 0.08em, uppercase |
| Label / подпись счётчика | 0.18em, uppercase |

**Правила для градиентного H1:** `padding-bottom: .12em` и `margin-bottom: -.12em`, `box-decoration-break: clone`, `text-wrap: balance`. Без padding обрезаются выносные элементы «д» и «у» (зафиксировано в PITFALLS).

**Ширина строки:** подзаголовок hero не шире `54ch`, описание карты не шире `42rem`.

## Color

Бюджет 60/30/10 считается по площади пикселей обеих секций.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#070210` (midnight-950) | фон hero, фон секции карты, фон океана под картой, подложка подсказки `rgb(7 2 16 / .55)` |
| Secondary (30%) | `#3b4da1` (unity-500) при alpha .55, `#211a3e` (midnight-800) при alpha .55, `#303f83` (unity-700) в стекле | заливка 12 стран ЕАД, заливка остальных стран, поверхность счётчиков и чипов, атмосферные пятна hero и карты |
| Accent A (5%) | `#d28ebe` (signal-300) | огоньки типа «человек», число счётчика «Человек», его точка-индикатор, левый край брендового градиента H1 |
| Accent B (5%) | `#7bc2c7` (horizon-400) | огоньки типа «группа», число счётчика «Групп», его точка-индикатор, правый край брендового градиента H1 |
| Accent-ссылка | `#aad9dc` (horizon-200) | eyebrow обеих секций, кольцо фокуса, обводка активного чипа |
| Destructive | не вводится | деструктивных действий в фазе нет |

**Accent зарезервирован строго за списком:**

1. Огоньки на карте (ядро и гало) и только они из декоративных элементов.
2. Числа счётчиков «Человек» и «Групп» плюс точки-индикаторы в их подписях.
3. Стопы брендового градиента H1 hero и H2 карты.
4. Кольцо фокуса `focus-visible` и обводка активного чипа (`horizon-200`).
5. Луч CTA (блик `#aad9dc` до `#f8eaf4` до `#fff`).

Accent не красит: фон секций, заливку стран, границы карточек, текст абзацев, hover обычных чипов, подсказку о жестах.

**Границы и обводки:**

| Элемент | Значение |
|---------|----------|
| Граница страны на карте | `rgb(184 192 230 / .28)`, 0.6px, `vector-effect: non-scaling-stroke` |
| Граница выбранной страны | `rgb(170 217 220 / .55)`, 1px, `non-scaling-stroke` |
| Граница счётчика | `rgb(184 192 230 / .22)`, 1px |
| Граница чипа (обычный) | `rgb(184 192 230 / .16)`, 1px |
| Граница чипа (hover) | `rgb(123 194 199 / .46)`, 1px |
| Граница чипа (активный) | `rgb(170 217 220 / .72)`, 1px |

**Контраст (расчёт по WCAG 2.1, перепроверить на билде в фазе 5):**

| Пара | Ratio | Порог | Итог |
|------|-------|-------|------|
| paper `#f8f7fb` на `#070210` | 19.0:1 | 4.5:1 | PASS |
| paper/0.82 (подзаголовок) на `#070210` | 12.7:1 | 4.5:1 | PASS |
| horizon-200 `#aad9dc` (eyebrow) на `#070210` | 13.3:1 | 4.5:1 | PASS |
| horizon-400 `#7bc2c7` (число «Групп») на `#070210` | 10.0:1 | 3:1 (крупный) | PASS |
| signal-300 `#d28ebe` (число «Человек») на `#070210` | 8.1:1 | 3:1 (крупный) | PASS |
| paper/0.72 (подсказка о жестах, 12px) на `rgb(7 2 16 / .55)` над `#070210` | 9.4:1 | 4.5:1 | PASS |
| unity-500 `#3b4da1`, средний стоп градиента H1, на `#070210` | 2.7:1 | 3:1 (крупный) | FAIL без правки |

**Правка градиента H1 (уточнение к locked-решению по требованию WCAG 1.4.3).** Средние синие стопы брендового градиента дают 2.7:1 и не дотягивают до 3:1 для крупного текста. Поверх брендового градиента кладём осветляющий слой в том же `background-image`:

```css
background-image:
  linear-gradient(0deg, rgb(248 247 251 / .18), rgb(248 247 251 / .18)),
  var(--gradient-brand-hero);
```

Средний стоп поднимается до `#5d6cb1`, контраст до 4.1:1, брендовый переход маджента-бирюза сохраняется. H2 карты использует градиент фазы 1 `104deg #e3afd2 2%, #8f9dd6 52%, #7bc2c7 98%`, у которого самый тёмный стоп `#8f9dd6` даёт 7.0:1, правка ему не нужна.

Глиф U+202F берётся из Noto Sans через стек `"Onest", "Noto Sans", sans-serif`, поэтому «тофу» не появится.

## Interaction Contract

| Взаимодействие | Поведение |
|----------------|-----------|
| Клик по CTA | переход к `#light-form`, плавный скролл с учётом высоты header (логика фазы 1), `behavior: "auto"` при reduced motion |
| Колесо над картой | зумит только с `ctrlKey` или `metaKey`; без модификатора страница скроллится обычным образом |
| Перетаскивание мышью | сдвигает карту, курсор меняется на `grabbing` |
| Один палец на карте | скроллит страницу (`touch-action: pan-y`) |
| Два пальца на карте | зумят и сдвигают (`zoom.filter` пропускает событие при `event.touches.length >= 2`) |
| Пределы | `scaleExtent([1, 8])`, `translateExtent` по размеру контейнера с запасом 200px |
| Клик по чипу страны | считает `geoPath.bounds(feature)`, целевой масштаб `min(8, 0.8 / max(dx / w, dy / h))`, переход 600ms `cubic-bezier(0.22, 1, 0.36, 1)` через rAF; чип получает `aria-pressed="true"`, остальные сбрасываются |
| Клик по «Весь дивизион» | возврат к `zoomIdentity` тем же переходом |
| Ручной зум после выбора чипа | активный чип сбрасывается на «Весь дивизион» только при изменении масштаба больше чем на 15%, иначе остаётся |
| Клавиатура | Tab доходит до CTA, затем до каждого чипа; Enter и Space активируют чип; сама карта в таб-порядок не попадает, её альтернатива это чипы |
| Наведение на огонёк | не предусмотрено: тултипы отложены в v2 |

**Состояния интерактивных элементов:**

| Элемент | default | hover | focus-visible | active | disabled |
|---------|---------|-------|---------------|--------|----------|
| CTA | градиент, луч крутится | подъём 1px, тень сильнее | кольцо `#aad9dc` 2px, offset 4px | `translateY(0)` | не бывает |
| Чип | стекло, светлая рамка | рамка horizon | кольцо `#aad9dc` 2px, offset 2px | масштаб 0.98 на 120ms | при ошибке карты: `opacity: .5`, `pointer-events: none`, `aria-disabled="true"` |
| Контейнер карты | `cursor: grab` | тот же | не фокусируется | `cursor: grabbing` | при ошибке показывает блок ошибки |

## Motion Contract

| Элемент | Анимация | Тайминг | При `prefers-reduced-motion: reduce` |
|---------|----------|---------|--------------------------------------|
| Глобус | вращение вокруг наклонённой оси | 0.0008 рад/кадр, rAF | rAF не запускается, рисуется один статичный кадр |
| Глобус, паузы | останов вне вьюпорта и при `document.hidden` | IntersectionObserver `threshold: 0` | правило сохраняется |
| Звёздное поле | дрейф `background-position` | 120s linear infinite alternate | анимация снята, звёзды статичны |
| Луч CTA | `--beam-angle` от 0deg до 360deg | 3s linear infinite | `animation: none`, угол фиксируется на 296deg, блик остаётся статичным в верхней части рамки |
| CTA hover | подъём и тень | 320ms `cubic-bezier(0.22, 1, 0.36, 1)` | `transition: none` |
| Пульсация огоньков | scale и opacity у ~40 огоньков | 2.4s ease-in-out infinite, delay `(i % 12) * 200ms` | `animation: none`, все огоньки статичны при `opacity: .9` |
| Новый огонёк | расходящееся кольцо | 900ms `cubic-bezier(0.16, 1, 0.3, 1)`, один раз | кольцо не рисуется, огонёк появляется сразу |
| Счётчики | count-up от 0 до значения | 1600ms, easeOutCubic, старт по IntersectionObserver `threshold: .4`, один раз | конечное значение сразу, без анимации |
| Зум по чипу | интерполяция transform | 600ms `cubic-bezier(0.22, 1, 0.36, 1)` | `zoom.transform` применяется мгновенно |
| Скролл к форме по CTA | плавный скролл | нативный smooth | `behavior: "auto"` |

Reveal-анимации секций (`whileInView`) добавляет фаза 5. Фаза 2 их не трогает.

## Accessibility Contract

| Элемент | Разметка и атрибуты |
|---------|---------------------|
| CTA | `<a href="#light-form">` с видимым текстом, без `aria-label` поверх текста |
| Ряд чипов | `<div role="group" aria-label="Показать страну на карте">`, внутри `<button type="button" aria-pressed>` |
| Счётчик | `<p>` с подписью и `<span aria-live="polite">` вокруг числа; число это текст, не canvas |
| SVG-карта | `role="img"`, вложенный `<title>` «Карта Евро-Азиатского дивизиона», `aria-describedby` на скрытый абзац `map.srDescription` с текущими числами |
| Огоньки и слой стран | `aria-hidden="true"` (декоративная графика, содержание доступно через счётчики и описание) |
| `GlobeCanvas` и `Starfield` | `aria-hidden="true"`, `pointer-events: none` |
| Подсказка о жестах | обычный текст, не `title`, читается скринридером |
| Блок ошибки карты | `role="status"` |

**Правила:**

- Кольцо фокуса видно на всех интерактивных элементах: `outline: 2px solid #aad9dc`, offset 2px или 4px. `outline: none` без замены запрещён.
- Тач-цели не меньше 44×44px до 768px: чипы получают высоту 44px, CTA держит 56px на всех ширинах.
- `@media (forced-colors: active)`: у H1 и H2 `-webkit-text-fill-color: currentColor`, градиент отключается, текст читается системным цветом.
- Порядок фокуса совпадает с визуальным: CTA hero, затем чипы слева направо и сверху вниз.
- Анимации подчиняются `prefers-reduced-motion` и в CSS, и в JS (`useReducedMotion` из `motion/react` для rAF и count-up).
