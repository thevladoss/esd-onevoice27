## Implementation Decisions

### Новости (`#news`)
- Скошенный верх секции (как переход в оригинале), фон midnight-900. Текст слева: eyebrow «На каждом канале», H2 «Каждая платформа становится голосом», абзац «Единый голос 27 встречает людей там, где они уже есть: на каждом экране и каждой частоте.»
- `data/news.ts`: 9 мок-новостей `NewsItem { id; title; date: string (ISO); cover: string; href: string; source: string }`, обложки `https://img.youtube.com/vi/{id}/hqdefault.jpg` роликов ЕАД, ссылки на `https://esd.onevoice27.org/materials/video` или YouTube. Заголовки: «5 сентября — всемирный день молитвы «Единый голос 27»», «Михаил Каминский: почему дивизион присоединяется к движению», «Эртон Келер о «Едином голосе 27»: одна весть на всех языках», «Руководители Адвентистской церкви — о проекте», «Что мы ожидаем от проекта «Единый голос 27»?», «Как отделы церкви поддерживают проект», «Как я могу поддержать «Единый голос 27»?», «Опубликованы баннеры к 5 сентября 2026», «Вопросы по книге «Желание веков»: материалы для малых групп»; даты с июня по сентябрь 2026, формат вывода «5 сентября 2026» через `Intl.DateTimeFormat("ru-RU", { day: "numeric", month: "long", year: "numeric" })`.
- Карточка: `article` с обложкой 4:5 (`object-fit: cover`), градиентный скрим снизу, дата мелким uppercase, заголовок Onest 800 22px поверх, вся карточка — ссылка (`target="_blank" rel="noopener noreferrer"`), hover: обложка `scale(1.04)`, рамка horizon-400/.4. Сетка 3 колонки на десктопе, 2 на планшете, 1 на мобильном.
- Пагинация (NEWS-02): `paginate(items, page, perPage = 6)` в `lib/paginate.ts` с тестами (2 страницы для 9 элементов, вторая содержит 3); кнопки «1», «2» и стрелка «→» (disabled на последней), активная с градиентом, `aria-current="page"`, `aria-label="Страница 2"`; смена страницы через `useState`, без роутинга, фокус остаётся на пагинации, скролл не прыгает.

### Ресурсы (`#resources`)
- Фон midnight-950 со звёздными точками (`radial-gradient` мелких точек) и дрейфующими частицами: 3 псевдо-слоя с `@keyframes resources-particles` (opacity .2→.6→.22, `translate3d` дрейф) 18–26s, выключены при reduced motion.
- Раскладка CSS grid 12 колонок × 3 ряда на десктопе, повторяет оригинал: карточка «Музыка» слева сверху (cols 1–4, rows 1–2), центральный текстовый блок (cols 5–9, rows 1–3): eyebrow «Ресурсы», H2 «Всё, что нужно для старта», абзац «Музыка, видео и материалы, которые помогут рассказать об инициативе в вашей церкви и городе.»; карточка «Материалы» справа со сдвигом вниз (cols 9–12, rows 2–3); карточка «Видео» снизу по центру-слева (cols 4–7, row 3 с отрицательным отступом). На мобильном стек: текст, затем три карточки.
- Карточка (RES-01): `GlassCard` высотой 256–336px, `flex-col justify-between`; сверху индикатор: подпись uppercase Noto Sans 12px letter-spacing .08em («МУЗЫКА» / «МАТЕРИАЛЫ» / «ВИДЕО») и точка 12px цвета акцента (музыка `#8f9dd6`, материалы `#7bc2c7`, видео `#d28ebe`); снизу заголовок Onest 800 22px («Пойте вместе», «Будьте готовы», «Смотрите и делитесь»), описание 14px paper/.8, ссылка-триггер uppercase 12px с градиентной линией («Открыть музыку», «Открыть материалы», «Открыть видео»). Вся карточка — `button` с `aria-expanded` и `aria-controls`; hover `translateY(-4px)` и рамка акцента; активная карточка держит рамку акцента.
- Панель (RES-02–04): `ResourcePanel` под сеткой, `GlassCard` с фоном `radial-gradient(circle at 15% 12%, rgb(79 93 175 / .2), transparent 38%)`, заголовок панели, описание, кнопка «Свернуть ×»; переключение через `useState<"music" | "materials" | "video" | null>`; повторный клик по активной карточке закрывает; при открытии панель плавно раскрывается (высота через `grid-template-rows: 0fr → 1fr`, при reduced motion мгновенно) и получает фокус (`tabIndex=-1`).
  - Материалы (`data/materials.ts`): «Описание проекта (на русском)» → `https://hope-documents.fra1.digitaloceanspaces.com/65e8ec8ed9988b1907692c05/mGS1787822852554.docx` (DOCX), «Баннеры к 5 сентября 2026» → `https://esd.onevoice27.org/materials/banners`, «Вопросы по книге «Желание веков»» → `https://esd.onevoice27.org/materials/desire-of-ages`, «Заставка для телефона» → `https://esd.onevoice27.org/materials/wallpapers`, «Материалы (на английском)» → SharePoint-ссылка из PROJECT.md; каждая строка с иконкой типа (документ, изображение, книга, телефон, папка), названием, подписью и стрелкой; внешние ссылки `target="_blank" rel="noopener noreferrer"`.
  - Видео (`data/videos.ts`): 16 роликов `{ id, title }` из PROJECT.md в сетке 4 × 4 (2 на мобильном), каждый — фасад `VideoEmbed` (постер `hqdefault`, кнопка play, iframe `youtube-nocookie` по клику), подпись названия под фасадом.
  - Музыка: заглушка `GlassCard` с иконкой ноты и текстом «Официальная песня «Единого голоса 27» скоро появится здесь. Следите за новостями дивизиона.»
- Тесты: `paginate.test.ts`; `News.test.tsx` (6 карточек на первой странице, 3 на второй, `aria-current`); `Resources.test.tsx` (клик по «Материалы» открывает панель с 5 ссылками и `aria-expanded="true"`, повторный клик закрывает, клик по «Видео» переключает панель и показывает 16 фасадов).

### Цитата (`#quote`)
- Секция между ресурсами и футером, фон `linear-gradient(180deg, #120c34, #211a3e)` с силуэтом карты мира: статичный SVG из `world-atlas` (все страны, `geoNaturalEarth1` или `geoMercator` fit по ширине), заливка paper/.05, границы paper/.1, `aria-hidden`; поверх мягкие пятна signal/unity.
- Контент по центру `max-w-3xl`: eyebrow «Слово на дорогу», `blockquote` двумя абзацами: «Пусть каждый работник в винограднике Господа исследует, планирует, разрабатывает методы работы с людьми. Нам необходимо предпринимать нечто выходящее за рамки обычного порядка вещей.» и «Мы обязаны приковывать внимание людей. Нам следует быть чрезвычайно серьезными. Мы стоим на самом пороге времени бедствий и смут, которые трудно вообразить.»; шрифт Onest 700 `text-xl md:text-2xl` line-height 1.35; `cite` «Эллен Уайт, «Евангелизм», стр. 122» uppercase 12px horizon-200; декоративные кавычки градиентом.
