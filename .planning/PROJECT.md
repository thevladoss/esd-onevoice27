# Единый голос 27 — лендинг Евро-Азиатского дивизиона (редизайн)

## What This Is

Одностраничный лендинг «Единый голос 27» для Евро-Азиатского дивизиона (ЕАД) Церкви адвентистов седьмого дня: структурная и визуальная копия оригинала https://onevoice27.org/ (тёмная фиолетово-бирюзовая тема, стеклянные карточки, карта с огоньками, форма «зажечь свет»), наполненная русскоязычным контентом ЕАД с https://esd.onevoice27.org/ и https://esd-map.vercel.app/. Рабочий прототип редизайна с замоканными данными, опубликованный на GitHub Pages.

## Core Value

Посетитель открывает страницу и видит красивый, живой лендинг уровня оригинала onevoice27.org, но про ЕАД: узнаёт, что такое «Единый голос 27», видит карту движения по дивизиону и может «зажечь свой свет».

### Out of Scope

- Реальная отправка формы и бэкенд — прототип, данные замоканы
- CMS и админка — оригинал живёт на Hope Software CMS, нам нужен только прототип редизайна
- Многоязычность — только русский
- Карта на тайлах (Mapbox/MapLibre) — нужны токены или внешние тайлы; собственный SVG на d3-geo даёт полный контроль над стилем
- Пиксель-перфект копия оригинала — цель «похоже и качественно», не 1:1
- Хотлинк фото с CDN ЕАД — используем локальную SVG/CSS-графику и YouTube-превью

## Constraints

- **Tech stack**: Vite 8 + React 19 + TypeScript, Tailwind CSS v4, motion, d3-geo/d3-zoom/topojson-client/world-atlas, Vitest + Testing Library — зафиксировано в спеке, чтобы билд был статическим и бесплатно хостился
- **Hosting**: GitHub Pages (репозиторий thevladoss/esd-onevoice27, base path `/esd-onevoice27/`) — единственный бесплатный хостинг с уже авторизованным CLI
- **Язык**: весь пользовательский текст на русском; идентификаторы на английском
- **Внешние зависимости в рантайме**: только Google Fonts (Onest, Noto Sans) и YouTube (превью и lite-embed); никаких токенов и API-ключей
- **Тесты**: test-as-you-go, тесты пишутся и прогоняются в той же фазе, что и код
- **Объём**: рабочий прототип, без задрачивания каждой детали

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Fallback MAP-06: дыхание радиуса ореола отключено, дышит только opacity | 942 SVG-ореола с анимируемым `r` держали 50,9 fps при пороге 50; opacity-версия — 71 fps | ✓ Good: 69,5 fps на проде, огоньки визуально как у оригинала |
| `@import "tailwindcss" source("..")` в global.css | Сканер Tailwind от корня подмешивал утилиты из строк планов и дампов оригинала; хэш бандла менялся от документов | ✓ Good: CSS 100,9 → 76,5 КБ, документы не влияют на бандл |
| Фазы 7–12 параллельно в worktree с владением файлами по фазам | Пользователь просил параллелить; конфликты слияния исключены списками файлов в ROADMAP | ✓ Good: шесть слияний без конфликтов, стыки проверены тестом App.seams |
| Собственная SVG-карта на d3-geo вместо Mapbox | Без токенов и внешних тайлов, полный контроль над фиолетовым стилем как в оригинале | ✓ Good: 177 стран и 942 огонька, зум и чипы стран, чанк vendor-map 183 КБ |
| Canvas-глобус из частиц вместо webm-видео | Нет исходного видео, canvas весит 0 байт и выглядит в духе оригинала | ✓ Good после фазы 5: яркость поднята до 125/255, ореолы без shadowBlur, 121 fps |
| Onest для заголовков вместо Figtree | Figtree без кириллицы, Onest ближайший геометрический жирный аналог с кириллицей | ✓ Good: заголовки читаются как в оригинале |
| `motion` для reveal-анимаций, CSS keyframes для фоновых | Оригинал делает всё на CSS + IO; motion даёт то же декларативно | ✓ Good: 31 обёртка Reveal, единый блок reduced motion, тест motionPolicy |
| GitHub Pages + Actions | Бесплатно, gh уже авторизован, деплой без сторонних CLI | ✓ Good: прод побайтно равен dist, права джоб минимальны |
| Мок-данные детерминированы (seed) | Стабильные тесты и одинаковая картина огоньков между сборками | ✓ Good: 335 тестов стабильны, огоньки одинаковы между сборками |
| Ореолы точек глобуса плоскими кругами, без shadowBlur (фаза 5) | shadowBlur стоил 533 мс на кадр на GPU, плоский круг в режиме lighter читается как свечение за 4 мс | ✓ Good: 121 fps в hero на проде |
| Шапка, меню, кнопка и фоны переносятся из живого CSS оригинала числами RGB, а не по именам токенов (фаза 6) | Пользователь просил «точно как в оригинале вплоть до анимаций и цветов»; палитра оригинала отличается от нашей (unity-500 = rgb(105 120 195)) | ✓ Good: пилюля совпала с оригиналом до пикселя, базовые цвета секций в пределах 2/255 |
| Горизонтальный overflow оригинала не копируется: секции карты и формы клипуют горизонталь (фаза 6) | У оригинала scrollWidth 2338 на 1920 из-за орба со сдвигом 38% | ✓ Good: scrollWidth равен ширине окна на 320…1920 |
| Onest подключён вариативным диапазоном 400..900 (фаза 6) | Оригинал использует веса 650 и 750, статические 700/800 округляли их | ✓ Good: document.fonts.check('650 16px Onest') → true |
| Оверлей мобильного меню внутри пилюли, бургер z 42 над оверлеем z 40 (фаза 6) | Как в оригинале: крест закрытия остаётся поверх оверлея, логотип и стекло уходят под него | ✓ Good: elementFromPoint по бургеру отдаёт бургер |
